# 复核补充：共同区间内全部 K≥33 的 s₁ 舍入公式与全局平局族

日期：2026-10-23。复核基线：`be32b88`。模型为 canonical XO、最小指标 argmax。

本引理处理无限 K 的第一轮选择，不声称已经证明全 K 的两轮全时间最优。下面的全称结论来自解析不等式；有限精确重放只作交叉核验。

## 1. 结论

令

```math
I=[1999/8000,2001/8000],\quad K\ge33,\quad
s_0=\lfloor K/2\rfloor,\quad y_0=s_0/K,\quad F_0=2y_0-y_0^2,
\quad \lambda=\alpha F_0.
```

则真实全局选择 s₁ 恰为距离

```math
v=K\left(\frac12+\frac34\alpha F_0\right)
```

最近的整数，半整数时取较小整数。此公式对全部 α∈I 一致成立。

因此，α=1/4 时，对全部 K≥33：s₁ 出现全局平局当且仅当 K≡32 (mod 64)；每次恰为两个相邻整数平局，真实选择较小者。有限核对 K=6..32 后，整个 K≥6 范围的 s₁ 平局集合为

```math
\{16\}\ \cup\ \{32+64n:n\ge0\}.
```

K=16 的并列指标为 {10,11}；K=32 为 {20,21,22}；其余平局 K≥96 恰有两个相邻并列指标。

## 2. 第一轮差异函数的精确表达

canonical 累积质量在格点 y=j/K 上为 P(y)=2y−y²，初态 D₀(y)=y(1−y)。其最小指标最大值是 s₀=⌊K/2⌋。第一轮更新后，在格点上有

```math
D_1(y)=
\begin{cases}
(1-\alpha)P(y)+\lambda G(y)-y,&j\le s_0,\\
P(y)-\lambda(1-G(y))-y,&j>s_0.
\end{cases}
```

两式在 y=y₀ 相同。将右侧延拓为分段连续函数只用于比较这些格点值，不改变离散模型。

K≥33 时，16/33≤y₀≤1/2，因此

```math
\frac{800}{1089}\le F_0\le\frac34,
\qquad \frac9{50}\le\lambda\le\lambda_{\max}:=\frac{6003}{32000}<\frac4{21}.
```

这里真实下界 α_min·800/1089=1999/10890>9/50。

## 3. 扫描前缀不产生竞争峰

对 y≤1/3 的扫描部分，D₁ 的导数为

```math
1-2\alpha-2(1-\alpha)y+\lambda/2
\ge\frac13-\frac43\alpha_{\max}+\frac9{100}
=\frac{539}{6000}>0.
```

对 1/3≤y≤y₀ 的扫描部分，导数满足

```math
1-2\alpha-2(1-\alpha)y+\frac32\lambda
\ge-\alpha+\frac32\lambda
=\alpha\left(\frac32F_0-1\right)
\ge\alpha\frac{37}{363}>0.
```

因此所有扫描格点的 D₁ 都不超过 D₁(y₀)。

## 4. 两个未扫二次峰的统一支配

在未扫中段 y₀<y≤2/3，

```math
P_M(y)=-y^2+(1+3\lambda/2)y-4\lambda/3,
\qquad y_M=\frac12+\frac34\lambda.
```

在 2/3≤y≤5/6，

```math
P_U(y)=-y^2+(1+2\lambda)y-5\lambda/3,
\qquad y_U=\frac12+\lambda.
```

两个连续峰值之差恰为

```math
\max P_M-\max P_U=\frac{\lambda(4-21\lambda)}{48}.
```

该式在当前 λ 区间递减，因此其统一下界是

```math
\Delta=\frac{\lambda_{\max}(4-21\lambda_{\max})}{48}
=\frac{3875937}{16384000000}.
```

取距 Ky_M 最近的整数 j，半整数时暂选较小者，置 y_j=j/K，h=1/K。由于 |y_j−y_M|≤h/2≤1/66，有

```math
y_j-y_0\ge\frac{27}{200}-\frac1{66}=\frac{791}{6600}>0,
```

以及

```math
\frac23-y_j\ge\frac23-\left(\frac12+\frac34\lambda_{\max}+\frac1{66}\right)
=\frac{45703}{4224000}>0.
```

所以此格点确实位于未扫中段，其真实 D₁ 等于 P_M(y_j)。格点舍入损失不超过 h²/4，且

```math
\Delta-\frac1{4\cdot33^2}
=\frac{124895393}{17842176000000}>0.
```

故此格点严格支配整个上段的连续峰，进而支配上段全部格点。y>5/6 时，D₁(y)=y(1−y)≤5/36=P_U(5/6)≤max P_U，也被严格支配。

同时，因为 D₁(y₀)=P_M(y₀)，

```math
P_M(y_j)-D_1(y_0)
\ge(y_M-y_0)^2-h^2/4
\ge\left(\frac{27}{200}\right)^2-\frac1{4\cdot33^2}
=\frac{783881}{43560000}>0.
```

结合前节的单调性，此格点也严格支配全部扫描格点。于是所有全局最大值都在未扫中段；该段抛物线对称且严格凹，最大格点恰为 Ky_M 的最近整数，半整数时有且仅有两个相邻最大格点。最小指标规则给出第 1 节公式。

## 5. α=1/4 的平局族闭合

偶 K 时 F₀=3/4，故 v=41K/64。半整数条件为 41K=64j+32，等价于 K≡32 (mod 64)。K≥33 时这给出 K=96,160,224,288,…。

奇 K 时

```math
F_0=\frac34-\frac1{2K}-\frac1{4K^2},
\qquad v=\frac{41K-6-3/K}{64}.
```

若 v=j+1/2，则 3/K=41K−38−64j 为整数；K≥33 时不可能。因此大奇 K 没有 α=1/4 的 s₁ 平局。剩余 K=6..32 的全部最大指标由独立 Fraction 重放枚举，只有 K=16 和 K=32 出现平局，详见复核数据。

## 6. 对下一步研究的含义与限制

偶 K≥34 时，在 I 内 s₁ 的真实切换点间距为 16/(9K)。所以固定单一选择字的许可区间宽度随 K 增大自然可以缩小；这不能作为真实两轮最优区间也必须缩小的证据。

可令 η₁=s₁−Ky_M，得到 −1/2≤η₁≤1/2，将此舍入误差纳入进入状态和损失系数的一致界。精确半整数时真实 η₁=−1/2；若只作充分条件的保守包络，覆盖整个闭盒 [−1/2,1/2] 是可行的，但不能据此把非真实状态称为真实轨道。

本引理尚未证明 t*=2 的全 K 一致性，也未完成 U₀、U₁、有限后缀与无限尾部的全 K 比较。它提供可直接接入这些工作的真实前缀参数化，并补齐此前仅确认局部二次峰的全局支配缺口。
