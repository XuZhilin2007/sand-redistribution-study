# 第一次操作后的选择规律 s₁(K)：两峰格点公式

> v0.2.0 正式收录，2026-10-07。范围与证据等级见[补充成果登记](XO_EXTENSION_REGISTRATION.md)，
> 独立审查来源见[补充审查记录](XO_EXTENSION_REVIEW.md)。实验室旧稿与修订历史在私人仓库保留。


## 1. 正确编号

s₀ 是初态 p₀ 的选择；一次更新后 p₁ 的选择为 s₁；
两次更新后 p₂ 的选择为 s₂。s₀=floor(K/2)。
原 s2_of 函数只做一次更新并除以 K，实际输出 s₁/K。
本轮修正为两次更新后输出 s₂，并分别记录 s₁/K 与 s₂/s₁。
例如 K=50：(s₀,s₁,s₂)=(25,32,41)，所以 s₁/K=16/25，
s₂/s₁=41/32，不是0.64。

## 2. 两峰公式

u=floor(K/2)/K，F₀=2u−u²。未扫侧 y=j/K>u：
D₁(y)=y−y²−(F₀/4)(1−G(y))。
在 [1/3,2/3]：
D₁=(1+3F₀/8)y−y²−F₀/3，
峰 y₂*=(1+3F₀/8)/2，V₂=(1+3F₀/8)²/4−F₀/3。
在 [2/3,5/6]：
D₁=(1+F₀/2)y−y²−5F₀/12，
峰 y₃*=(1+F₀/2)/2，V₃=(1+F₀/2)²/4−5F₀/12。

**命题 D**：s₁ 是以下至多6个候选的最小 argmax：
floor/ceil(Ky₂*)，floor/ceil(Ky₃*)，floor/ceil(2K/3)，
只保留 s₀<j≤K，并用实际分段 D₁(j/K) 比较。

## 3. 全 K 候选归约

K≥6 时 3/7≤u≤1/2。
被扫侧第一段的导数至少 F₀/8>0；
第二段导数在 y≤u 时至少 1/2−3u/4−3u²/8≥1/32>0。
故被扫侧最大值在 u，且 V₂−D₁(u)=(y₂*−u)²≥81/4096。

最近 y₂* 的格点距离≤1/(2K)，在 u 右侧且<5/6：
y₂*−u≥9/64>1/(2K)，y₂*+1/(2K)≤41/64+1/12<5/6。
若该格点略超过2/3，实际第三段值高于第二段二次型延拓值：
差为 F₀(y−2/3)/8≥0。
因此实际损失≤1/(4K²)≤1/144<81/4096，被扫侧不可能获胜。

平坦尾区 y≥5/6 的值≤5/36，
而 V₂≥657/4096、最近格点值≥657/4096−1/144>5/36，
故尾区也不可能获胜。
剩下两个凹二次段；各段最大格点在峰的相邻格点或共同边界附近，
即命题列出的候选。

偶数 K：F₀=3/4，y₂*=41/64，y₃*=11/16，
V₂=657/4096，V₃=656/4096，峰差1/4096。
比较有效段内最优格点时，若 δ₂、δ₃ 为以格点指标单位计的峰距离，
段3胜出的条件为 δ₂²−δ₃²>K²/4096；平局取小指标。
实际实现始终直接比较分段值，避免把位于另一段的相邻格点误当峰段格点。

## 4. 验证和撤回范围

mine_descent.py 沿用 K=6..4000 的3995个第一层实例，
以通分后的精确整数全 bin 扫描对照至多6个候选的 Fraction 比较。
辅助验收另从质量更新重建 D₁，核对整数分数值与选择编号。
K=6..60 的两次更新结果仅作为修正后的有限数据输出；
不声称第二层与第一层同构，也不声称有限样本证明“不收敛”。

原第一层全域措辞改为“解析证明对所有 K；计算验证限 K=6..4000”。
本轮不继续挖掘更深级联。
