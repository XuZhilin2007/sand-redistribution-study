## 1. 词典与旋转数等于长期 B-频率（提升论证）

采用[文献继承说明](V030_RELATED_WORK.md)中的精确词典（全部 CYCLE 类，含 r=5）：
$`(\lambda,\mu,\delta)=\bigl(\tfrac34,\ \tfrac{4\beta}{3},\ 1-\tfrac34\eta\bigr)`$，
阈值 $`\eta_{LN}=\eta`$，站立假设严格成立。

**命题 F1（$`\rho`$ = 长期 B-频率）。** 在 LN 的半共轭
$`F(\phi(y))=\phi(y+\rho)`$（其 Lemma 4.2）下，分支由
$`\{y\}<1-\rho`$（A 支）或 $`\{y\}\ge1-\rho`$（B 支）决定。沿旋转轨道
$`y_k=\{y_0+k\rho\}`$，B-步的集合是 $`\{k:\{y_0+k\rho\}\ge1-\rho\}`$——
旋转不变测度下测度为 $`\rho`$ 的区间，故其密度为 $`\rho`$。又
$`F^n(\phi(y_0))=\phi(y_0+n\rho)=\phi(\{y_0+n\rho\})+\lfloor y_0+n\rho\rfloor`$
给出 $`\lim_n(F^n(x)-x)/n=\rho`$。**因此旋转数等于长期 B-频率
$`\rho=\lim_n\#\{k<n:\text{第 }k\text{ 步为 B}\}/n`$。**
数值核验：$`K=9`$: $`1/12`$；$`K=10`$: $`9/22`$；$`K=65`$: $`11/16`$；
$`K=99`$: $`3/29`$（= 证书字的 B-计数/周期，逐例精确相等）。

**命题 F2（$`\rho`$ ↔ 短游程密度换算，r=3 混合区）。** r=3 的字由
$`BA^{a_1}BA^{a_2}\cdots`$ 组成（B-游程恒 1）。设短（长度 8）游程占比
$`d`$，则平均 A-游程长 $`\bar a=9(1-d)+8d=9-d`$，故

```math
\rho=\frac{1}{1+\bar a}=\frac{1}{10-d}.
```

验证：$`d=\tfrac13\Rightarrow\tfrac3{29}`$（$`K=99`$ ✓）；
$`d=\tfrac12\Rightarrow\tfrac2{19}`$（$`K=105`$–$`171`$ ✓）；
$`d=\tfrac23\Rightarrow\tfrac3{28}`$（$`K=177`$–$`189`$ ✓）；
$`d=1\Rightarrow\tfrac19`$（$`K\ge195`$ 纯 $`BA^8`$ ✓）；
$`d=0\Rightarrow\tfrac1{10}`$（纯 $`BA^9`$ ✓）。**短游程密度与旋转数是
不同的量**（$`K=99`$：$`d=\tfrac13\ne\rho=\tfrac3{29}`$）——混用即错。

## 2. 平台分类定理（LN 路径独立重推导整个字表）

**命题 F3（平台分类）。** 用 LN 定理 1(i) 的显式端点（$`S`$ 为机械和）：

```math
\delta^+=\frac{(1-\lambda)(1+\mu S+\lambda^{q-1}\mu^p(1-\lambda))}
{1+(\mu-1)S+\lambda^{q-1}\mu^{p-1}(\mu-\lambda\mu-1)},\qquad
\delta^-=\frac{(1-\lambda)(1+\mu S)}{1+(\mu-1)S-\lambda^q\mu^{p-1}},
```
