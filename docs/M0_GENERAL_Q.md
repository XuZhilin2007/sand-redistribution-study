# 一般 throw distribution 下的 M0 机制（General-q Analysis）

> 状态：Phase 2A 理论分析文档（2026-09-18）
>
> 配套实验：[M0.2 报告](../experiments/m0_2_distribution_family/M0_2_REPORT.md)；前置：[M0_MODEL.md](M0_MODEL.md)、[M0_MECHANISM.md](M0_MECHANISM.md)
>
> 证据等级声明：本文附录中的全部等式由 M0 的更新规则对**任意固定 q** 严格推导，属 **模型推导数学结果（Model-derived Mathematical Result）**，并已对照 canonical 模拟器独立核验（含一个不属于任何分布族的测试分布）。所有结论只对 fixed-q / fixed-zone 的 M0 类模型成立。

本文回答一个唯一问题：

> M0/M0.1 中发现的 finite-time optimum 与 time-rescaling，是 `q(x)=2(1-x)` 的特殊巧合，还是一整类 throw distribution 共有的结构？

**答案：是一整类模型的结构性质。** 形状锁定、单变量轨迹、alpha 时间重标定对**任意固定 q** 成立（条件见 §A.3）；interior optimum 是否存在由 q 的一个可计算不等式（`c_n > c_f`）完全决定；`q_near` 只是该理论内部的一个普通点。

---

# 第 1 层：直觉解释（不需要微积分）

## 1.1 形状锁定与"一个旋钮"对任意 q 都成立

M0.1 发现的机制与 q 的具体形状无关，只依赖 M0 的三条规则：初始状态就是 q、每轮回收固定近区、重泼永远用同一个 q。这三条对任何 q 都成立，所以：

- **近区图案永远不变**：每格按同一比例被拿走，再按同一形状补回——任何 q 都一样，"调暗图片"的比喻普适；
- **远区图案永远不变**：只接收 q 形状的补充；
- **一个旋钮 z 控制全局**：近区幅度 = z，远区幅度由总质量守恒自动确定。z 每轮乘以 `(1 − alpha × (1−Q))`，其中 Q 是 q 落在近区的质量份额——q 只通过这一个数字影响速度。

## 1.2 什么时候存在"先变好再变坏"？

把均匀度误差想成两笔账：近区的账（幅度 z 偏离自己的舒服点）加远区的账（幅度偏离自己的舒服点）。哪笔账更"陡"，取决于 **q 的图案在那一区里有多"尖"**。定义每单位质量的集中度：

- `c_n` = q 图案在近区的集中度（近区形状的平方和 ÷ 近区质量）；
- `c_f` = q 图案在远区的集中度。

**判断规则只有一行：**

| 条件 | 行为 |
|---|---|
| `c_n > c_f`（近区图案更尖） | 存在有限时间 interior optimum：先改善，后恶化 |
| `c_n = c_f`（恰好一样尖） | 边界情形：t=0 已是全程最佳，任何操作都变差 |
| `c_n < c_f`（远区图案更尖） | t=0 最佳，单调恶化，无改善阶段 |

直觉：只有当"近区的图案比远区更尖"时，把近区整体调淡才能先把误差降低——因为近区密集格子的"过高"是主要误差来源；一旦远区图案更尖，回收近区只会把误差搬来搬去并放大。

这个判据**只看 q 的初始形状，与 alpha 无关**——alpha 不能把一个"没有 interior optimum"的 q 变成"有"。

## 1.3 alpha 仍然只是速度旋钮

对任意固定 q：z 的路线（以及 U 沿这条路线的整条曲线、路线上的最低点 z*）完全由 q 决定；alpha 只决定每轮沿路线走多远（`×(1−alpha(1−Q))`）。同一 q、不同 alpha 的所有轮次点落在**同一条** U(z) 曲线上。极端：alpha=1 时 z 每轮直接乘 Q，几步就走完全程；alpha=0 时原地不动。

## 1.4 幂族里的答案

在冻结的单参数幂族 `q_p(x) = (p+1)(1−x)^p`（p=0 均匀、p=1 现有 baseline、p>0 近偏、p<0 远偏）中，判据可以算出闭式：

```text
c_n / c_f = (2^(2p+1) − 1) / (2^(p+1) − 1)      连续版本，a = 0.5
```

所以 **interior optimum 存在 ⟺ p > 0**（任何近偏都存在，无论多轻微）；p=0 是精确边界；p<0 一定没有。最佳轮次随近偏强度单调后移（p=0.25→1 轮，p=0.5→2 轮，p=1→4 轮，p=2→11 轮，baseline alpha=0.25）——近偏越强，重泼时落回近区的份额越大，z 前进越慢，最佳时刻越晚。这些全部在运行模拟**之前**由公式算出。

# 第 2 层：Mathematical Appendix

## A.1 记号

固定 `a = 0.5`（近区 = `x < a`；一般 a 只要求落在 bin 边界上）、K bins、q 为 `[0,1]` 上任意归一化分布。定义：

```text
Q   = Σ_{近区} q_i          （q 的近区质量，要求 0 < Q < 1）
Q_f = 1 − Q
S_n = Σ_{近区} q_i²          （近区形状集中度）
S_f = Σ_{远区} q_i²
```

全部由精确 bin 概率求和，无数值近似。q 通过 `power_distribution` 工厂或任意满足 CDF/bin-probabilities 接口的分布给出。

## A.2 一般闭式解（shape preservation + 一维轨迹）

**命题**：对任意满足 `0 < Q < 1` 的固定 q 与任意 `alpha ∈ [0,1]`，deterministic 期望质量动力学的精确解为

```text
近区：m_i(t) = z_t · q_i,     z_t = ρ^t,   ρ = 1 − alpha·(1−Q),  z_0 = 1
远区：m_i(t) = λ_t · q_i,     λ_t = (1 − Q·z_t)/Q_f
```

**归纳证明**：t=0 时 z=1、λ=1，状态为 q。设 t 成立，近区质量 `M_t = Q·z_t`：

- 近区：`m' = (1−alpha)z_t q_i + alpha·Q·z_t·q_i = z_t(1−alpha(1−Q))q_i = z_{t+1}q_i`；
- 远区：`m' = λ_t q_i + alpha·Q·z_t·q_i`，而 `λ_{t+1} − λ_t = Q(z_t−z_{t+1})/Q_f = alpha·Q·z_t` ✓；
- 总质量 `Q·z_t + Q_f·λ_t = Q·z_t + 1 − Q·z_t = 1` 恒成立。

因此整个 deterministic 系统由单一状态变量 z 描述，且**两区形状保持 q 的形状**（shape preservation）——推导未使用 q 的任何具体性质。

**核验**：(a) 用一个不属于幂族的非对称分段线性 q 对照模拟器：状态最大偏差 1.4×10⁻¹⁷、U 最大偏差 5.2×10⁻¹⁸；(b) 幂族六个成员：≤1.1×10⁻¹⁷（见 `tests/test_m0_2_family.py`、M0.2 `comparison.csv`）。

## A.3 Time-rescaling 的成立条件

**命题**：状态路径 `{m(z) : z ∈ (0,1]}`、二次函数 `U(z)` 及其最小点 z* 与 alpha 无关；alpha 只通过 `z_t = ρ^t` 决定轮次到路径位置的映射。

**成立所需条件（全部是 M0 定义的一部分）**：

1. **固定 q**：初始分布与每一次重泼都用同一个 q（若重泼分布随状态或轮次变化，路径随 alpha 改变，性质失效——Phase 3 的状态依赖策略正是从此处进入）；
2. **固定近区**（a 不随时间变化）；
3. **线性期望质量动力学**（deterministic 版本；MC 版本在期望意义上成立）；
4. **`0 < Q < 1`**：Q=0 时近区为空、无动作发生；Q=1 时远区无质量、λ 发散（退化）；
5. **`alpha ∈ (0,1]`**：alpha=0 时 ρ=1，z 恒为 1，不存在时间推进（合法但平凡）。alpha=1 给出 ρ=Q ∈ (0,1)，仍然遍历全路径。

在这些条件下，time-rescaling 对**任意** q 成立；无需 q 单调、对称或属于任何特定族。

## A.4 精确二次函数与最优点

由 `Σ(p_i−1/K)² = Σp_i² − 1/K` 与 `λQ_f = 1 − Qz`：

```text
U(z) = z²·S_n + S_f·((1−Qz)/Q_f)² − 1/K          （对任意 q 精确）
```

最小点：

```text
z* = Q·S_f / (Q_f²·S_n + Q²·S_f)
```

## A.5 Interior optimum 的一般条件

**命题**：z* < 1（从而从初始状态 z=1 出发先改善、后恶化）**当且仅当**

```text
Q_f·S_n > Q·S_f      ⟺      c_n > c_f,   c_n ≡ S_n/Q,  c_f ≡ S_f/Q_f
```

**证明**：`z* < 1 ⟺ Q·S_f < Q_f²·S_n + Q²·S_f ⟺ Q(1−Q)S_f < Q_f²·S_n ⟺ Q·S_f < Q·... ` 逐项：`Q S_f − Q²S_f = Q·Q_f·S_f`，故条件化为 `Q·Q_f·S_f < Q_f²·S_n`，即 `Q·S_f < Q_f·S_n` ∎

三个 regime 的行为：

- `c_n > c_f`：z* ∈ (0,1)，且 U(z*) < U(1)（抛物线最小点严格低于 z=1 处），**finite-time interior optimum 存在**；
- `c_n = c_f`：z* = 1，路径上（z ≤ 1）U 随 z 减小单调上升，t=0 最佳；
- `c_n < c_f`：z* > 1，同上单调上升，t=0 最佳。

regime 由 q 唯一决定，与 alpha 无关（§A.3）。

补充（非本轮重点但可由同一公式读出）：长期终态（z→0，`λ→1/Q_f`）是否比初始更差，由 `S_n/S_f < 1/Q_f² − 1` 决定；冻结的六个 case 全部满足，故终态都比初始差。

## A.6 幂族闭式

`q_p(x) = (p+1)(1−x)^p`，`a = 0.5`。记 `u = 2^{−(p+1)}`（= Q_f 的连续值；`Q = 1−u`）。连续版本（`∫q² = (p+1)²/(2p+1)`，要求 `p > −0.5`；离散实现只需 `p > −1`）：

```text
c_n/c_f = (2^(2p+1) − 1) / (2^(p+1) − 1)
z*_cont = 2(1−u) / (3 − 4u)
```

- interior ⟺ `c_n/c_f > 1` ⟺ `2p+1 > p+1` ⟺ **p > 0**；
- `p → ∞`：c 比值 ≈ 2^(p+1)，z* → 2/3（近偏无限强时退回"两区各自内部均匀"的直觉极限——但到达它的时间 t* → ∞，因为 ρ → 1）；
- `t* = ln(z*) / ln(1 − alpha·u)`：p ∈ {0.25, 0.5, 1, 2} 在 alpha=0.25 下分别为 1.16 / 2.21 / 4.46 / 11.23 → 预测离散最佳轮 1 / 2 / 4 / 11。

**有限-bin 修正（如实记录）**：离散 100-bin 实现与连续闭式存在 O(1/K) 偏差，随 bin 内形状集中度增长：p=−0.25 的 c 比值离散 0.6174 vs 连续 0.6075（+1.6%）、z* 离散 1.29451 vs 连续 1.30439（−0.76%）；p ≥ 0 各 case 修正在 0.5% 以内。预测表同时给出两个版本，离散模拟以离散 z* 为准。

## A.7 均匀对照的精确轨迹

p=0（q_uniform）：`U(t) = (1/K)·(1 − (1−alpha/2)^t)²`；alpha=0.25、K=100 时 `U(t) = 0.01·(1 − 0.875^t)²`。与模拟器逐轮偏差 6.9×10⁻¹⁸。这是"操作只能破坏均匀初始态"的精确刻画。
