# 限定探针：特定强制选择规则与有效初态的有限探针

> v0.2.0 正式收录，2026-10-07。范围与证据等级见[补充成果登记](XO_EXTENSION_REGISTRATION.md)，
> 独立审查来源见[补充审查记录](XO_EXTENSION_REVIEW.md)。实验室旧稿与修订历史在私人仓库保留。


## 1. S12 的准确问题与结论

K∈{8,14,26,50,200}，XO、α=1/4，canonical 轨迹先运行到首次自然选择 m。
此时所有内部坐标<a，x=p_m>h。
以后每轮以概率 ε 强制使用 ℓ 更新；否则使用自然选择。
ε∈{0.01,0.05,0.10,0.20}，每组200000轮标量浮点代理，沿用原随机种子；仅初始化阶段推进完整质量状态。

特定规则下上支保持：
强制 ℓ：x'=x+(c−x)q/4≥x>h；
自然 m：x'=(3/4)x+cq/4>h（LOCK 类 cq>h）。
内部坐标<a 的区域在这两种前缀更新下保持。
数学不变性说明自然 argmax 仍为 m、discrepancy d=a。长程脚本仅推进 x 并据闭包推算 d；不能把代理统计称作 200000 轮完整状态测量。

该结果描述一个有方向性的强制规则，不证明任意选择噪声、质量扰动、
核变化或实际噪声环境的稳定性。原“噪声无法把 LOCK 踢成 CYCLE”的一般说法撤回。

## 2. 指标修正

脚本分别记录：
- forced_share：实际强制轮数/H；
- unforced_share：实际未强制轮数/H；
- selected_lower_share：本设计中等于 forced_share；
- proxy_d_plateau_share：由标量闭包每轮推算 d=a，本设计为1；
- forced_run_length：连续强制输入的串长，不是 discrepancy excursion；
- proxy_max_d_excess：本设计的代理值为0。

未强制份额的期望为1−ε，有限样本通常接近该值，不能说每次精确等于1−ε。
串长统计来自 Bernoulli 输入本身，不能作为新动力学发现。
200000 轮统计不是完整质量向量的逐轮测量。另用完整质量状态 exact 算术对 K=8、50、200 各检查 33 轮强制选择，逐轮核对真实 d 与 argmax；该短程核对独立列在验收结果中。

## 3. S6 有效初态与范围

K=20,50,100，H=1000。每个初态和每个更新状态均断言质量非负且总和1。
停机判据在更新前执行。
保留 canonical、uniform、固定种子的 near_uniform 三种初态。
将旧 suffix_violate 改为 suffix_transfer_stop_control：
从首 bin 向末 bin 搬 take=min(1/20,p₀[首 bin]/2)，以保证非负。
这类构造所有前缀偏差≤0，按模型停止规则 t=0 停止；只作为停止负对照，
不用于声称初态鲁棒性或“违反后缀支配导致长期停机”的新结论。

原 K=50、100 固定搬走1/20的首 bin 分别为−3/100、−1/25，
不符合模型前提，相关旧案例撤回。
near_uniform 的观测只限各一个固定样本与1000轮，不外推吸引域或渐近不停机。

## 4. 本轮处置

保留特定强制规则的数学不变性说明及纠正后的统计；
保留有效初态的有限观察；撤回一般噪声稳定性、d 瞬时抬升、
有限样本份额精确等于1−ε、负质量样本和广义初态鲁棒性解读。
本轮不扩展噪声模型或初态研究范围。
