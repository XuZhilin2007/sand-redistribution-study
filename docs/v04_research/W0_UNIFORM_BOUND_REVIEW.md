# 复核补充：用 L¹ 收缩与格子方差闭合全部 K 的 W0

日期：2026-10-23。基线：`e489f87`。仅讨论 canonical XO，α∈J=[1999/8000,2001/8000]。

**结论：对全部整数 K≥6、全部 α∈J，U₀>U₂ 且 U₁>U₂。**

K≥145 的结论来自下述统一解析误差界；K=6..144 由已独立验收的原 203 个 K 区间证书承接。此结论只闭合 W0，尚不涵盖全部大 K 的 t≥3、统一进入或无限尾部。

## 1. 所用依赖与显式常数

依赖 `LARGE_K_PREFIX_LEMMA_REVIEW.md`：K≥33、α∈J 时，s₀=⌊K/2⌋，令 h=1/K、u₀=s₀h、F₀=2u₀−u₀²，则

```math
u_1=s_1h=\frac12+\frac34\alpha F_0+\eta h,
\quad |\eta|\le\frac12,
\quad \frac12<u_1<\frac23.
```

定义连续中央分支的选择点 v₀=1/2、v₁=1/2+9α/16。下文证明

```math
|U_1(K,\alpha)-\mathcal U_1(\alpha)|\le\frac{11}{10K},
\qquad
|U_2(K,\alpha)-\mathcal U_2^M(\alpha)|\le\frac{5}{2K}
\qquad(K\ge33,\ \alpha\in J).
```

两个误差在比较 U₁−U₂ 时相加，总常数为 18/5；对 U₀ 使用精确式 U₀=1/3−1/(3K²)。无需测量常数替代证明，也无需再向上扩充三点扫描。

## 2. 让离散状态成为密度的精确格子积分

设 f₀(y)=2−2y，g(y)=G′(y) 为 XO 分段常数密度，取值依次为 1/2、3/2、2、0；三个跳点为 1/3、2/3、5/6，跳跃量为 1、1/2、−2。

对任意 cutoff u，定义质量保持的正线性算子

```math
T_u f=(1-\alpha\mathbf1_{[0,u]})f
       +\alpha\left(\int_0^u f\right)g.
```

令 `f̃₁=T_{u₀}f₀`、`f̃₂=T_{u₁}f̃₁`，并记 A_h 为每个宽 h 格子上的平均算子。因为 u₀、u₁ 都是格子端点，canonical p₀ 与 g_i 本来就是 f₀、g 的格子积分，所以对 t=0,1,2 精确有

```math
p_{t,i}=\int_{(i-1)h}^{ih}\widetilde f_t(y)\,dy,
\qquad U_t(K,\alpha)=\int_0^1(A_h\widetilde f_t-1)^2\,dy.
```

连续参考态则为 f₁*=T_{v₀}f₀、f₂*=T_{v₁}f₁*，记 𝒰_t=∫(f_t*−1)²。J 严格位于中央峰支配区，故此处没有跨分支的极限歧义。

## 3. 选择点误差与 L¹ 收缩

对任意带符号可积函数 z，由 ∫g=1 得

```math
\|T_u z\|_1
\le\|z\|_1-\alpha\int_0^u|z|+\alpha\left|\int_0^u z\right|
\le\|z\|_1.
```

对非负 f，若 ‖f‖∞≤2，则

```math
\|T_u f-T_v f\|_1\le2\alpha\int_{\min(u,v)}^{\max(u,v)}f
\le4\alpha|u-v|.
```

初态选择误差 |u₀−v₀|≤h/2；又 |F₀−3/4|≤h/2+h²/4，所以

```math
|u_1-v_1|\le h\left(\frac12+\frac{3\alpha}{8}+\frac{3\alpha h}{16}\right).
```

固定便于复验的上界 ᾱ=251/1000、h̄=1/33，置

```math
\kappa=\frac12+\frac{3\bar\alpha}{8}+\frac{3\bar\alpha\bar h}{16}
=\frac{104817}{176000}.
```

于是

```math
\|\widetilde f_1-f_1^*\|_1\le2\alpha h,
\qquad
\|\widetilde f_2-f_2^*\|_1\le(2\alpha+4\alpha\kappa)h.
```

此处第二式先在相同 u₁ 下使用收缩性，再对 f₁* 的两个 cutoff 比较；没有对依赖状态的 argmax 算子假设收缩性。

## 4. 密度的统一界与损失的 Lipschitz 常数

两种第一步参考选择都满足 16/33≤u₀≤1/2，且第一步重撒质量 λ₀=αF₀≤3α/4。

在扫描区，g≤3/2，故 f₁≤2(1−α)+9α/8=2−7α/8<2；未扫区则 f₁≤34/33+3α/2≤34/33+3ᾱ/2<2。这同时适用于离散 cutoff 密度与连续参考密度。

第二步选择均在 (1/2,2/3)。第二次重撒质量 ν=α∫₀ᵘ¹f₁≤α。扫描区 f₂≤2(1−α)+3α/2<2；未扫区 y>u₁>1/2，也未被第一步扫描，故

```math
f_2=f_0+(\lambda_0+\nu)g\le1+\frac72\alpha<2
```

（ᾱ<2/7）。这些密度全非负，质量全为 1，因此对所比较的密度 F,H，

```math
\left|\int(F-1)^2-\int(H-1)^2\right|
\le\int|F-H|\,|F+H-2|\le2\|F-H\|_1.
```

## 5. 格子平均损失：精确方差与跳点界

有正交分解

```math
\int(F-1)^2-\int(A_hF-1)^2=\|F-A_hF\|_2^2\ge0.
```

对 F=f̃₁、f̃₂，每个格子内斜率绝对值≤2；选择点都是格子边界，因此格子内部只可能在 XO 密度的三个固定跳点处不连续。因 h≤1/33，一个格子至多含一个这样的跳点。

一个格子内函数写成 ay+b+J₀·1_{y>y_jump}，跳点相对位置为 θ∈[0,1]，则该格子的平均方差精确为

```math
\frac{a^2h^3}{12}+aJ_0\theta(1-\theta)h^2
+J_0^2\theta(1-\theta)h
\le\frac{h^3}{3}+\frac{|J_0|h^2}{2}+\frac{J_0^2h}{4}.
```

若全部 XO 跳跃的密度乘子不超过 B，则 Σ|J₀|≤7B/2、ΣJ₀²≤21B²/4。汇总全部格子得到

```math
\|F-A_hF\|_2^2
\le\left(\frac13+\frac{7B}{4}\right)h^2+\frac{21B^2}{16}h.
```

第一步可取 B₁=3ᾱ/4。第二步的乘子在选择点下方为 (1−α)λ₀+ν，上方为 λ₀+ν，因此可取 B₂=7ᾱ/4。

定义

```math
V(B)=\left(\frac13+\frac{7B}{4}\right)\bar h+\frac{21B^2}{16}.
```

结合前两节，误差常数可以取

```math
C_1^{\rm raw}=4\bar\alpha+V(3\bar\alpha/4)
=\frac{27133195711}{25344000000}<\frac{11}{10},
```

```math
C_2^{\rm raw}=4\bar\alpha+8\bar\alpha\kappa+V(7\bar\alpha/4)
=\frac{12603549611}{5068800000}<\frac52.
```

这就证明第 1 节的两个离散误差界，且是对全部 K≥33、全部 α∈J 的统一界。

## 8. α=16/63 的分支备注

上面统一证明只用 J，不跨过 16/63。在较宽候选窗口讨论“连续极限”时要保留两种分支的含义：在 α*=16/63，y_M=9/14、y_U=29/42 的连续峰值相同，但第二步状态与损失并不相同，且

```math
\mathcal U_2^U(\alpha^*)-\mathcal U_2^M(\alpha^*)
=-\frac{2504032}{2315685267}\ne0.
```

这里可直接闭合全局支配：偶 K 的 F₀=3/4、λ₀=4/21。扫描部分在前两段的最小导数分别为 17/189、2/63，故扫描前缀最大值为 D₁(1/2)=5/36；后缀 y≥5/6 的最大值也是 5/36。两个未扫连续峰均为 281/1764，比 5/36 高 1/49。

对 n≥1，偶 K=42n 时两峰恰在格点 27n、29n 上，按最小指标取中央峰；K=42n+4 时中央峰和上峰的最近格点分别为 27n+3、29n+3，格点距离分别为 3/7、5/21。后者的二次峰损失更小，所以真实 s₁=29n+3。相应格点损失均小于 1/49，扫描前缀与后缀不会竞争。

沿这两个固定分支，cutoff 误差趋零、固定 cutoff 算子 L¹ 收缩且格子平均方差趋零，故离散 U₂ 分别收敛到上列两个不同的积分值。不能在该点定义一个适用于所有 K→∞ 的单值 𝒰₂，也不能用分支公式的一个闭端点约定消除此问题。

两支的 W0 极限余量都为正仍是有效事实；当前 J 与该切换点有正距离，故不影响本文结论。
