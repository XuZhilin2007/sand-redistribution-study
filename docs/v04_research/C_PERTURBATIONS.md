## C1 尾部泄漏：g_ε=(1−ε)g_XO+εu（自然停机语义）

### 勘误（R2/R5，撤回第一波的两条结论）

- **撤回"泄漏版边界循环"长期结论**：第一波脚本漏掉自然停机，
  停机后仍强制选择更新，后续轨道是非法形式延拓。修复后：过程
  总在有限时间到达自然停机，不存在无限循环。
- **撤回"越界时间≈0.7/ε"估计**：该系数错误（把缺口误写为
  (1−b)h 而非正确的 h(2b+h−1)）。已由已证必要下界取代（下述）。

### R5 必要下界（复核者推导，本仓机器逐步核验）

在全部既往活跃选择 s≤m 期间，对 j≥m（y=j/K，R_t=Σ_{k<t}M_k）：

```math
D_{t,j}=D_{0,j}-\varepsilon(1-y)R_t,\qquad
D_{t,j}-D_{t,m}=(y-b)\bigl[\varepsilon R_t-(b+y-1)\bigr].
```

首次合法活跃选择 s>m 需 εR_t>2b+h−1，而 R_t≤αt，故**必要**
t>(2b+h−1)/(αε)。`leak_probe.py` 在每一步对恒等式做**精确
Fraction 相等断言**（15 组全部成立），并在首次越界点核验下界：
K=12、ε∈{1/4,1/10,1/20}：t=14>12、34>30、67>60 ✓。

### 修复后的 C1 主结果 [已验证计算结果]

   K=6/9/12、ε=1/10 → t=38/40/44；ε=1/20 → 75/78/86；
   ε=1/100 → 371/387/429；ε=1/1000 → 3700/3865/4283。
   浮点显示停机时刻 ≈ **3.7/ε** 线性标度（有限 ε 观测，非渐近定理）。
2. **停机态非均匀**：停机时 d≈0（一切前缀差异 ≤0）但

   逐格均匀（纪律 §4 的实例）。
3. **两轮停止在合法轨道上稳健**：K=6、12 全部 ε≤0.1：窗口
   argmin=2、无 U(t)<U(p_2)（`later<U2=False`）；**K=9 在
   ε≥1/20 时 argmin=3**（薄余量成员对扰动最敏感，与 A/B 方向
   观察一致），ε≤1/100 时恢复 argmin=2。
4. **合法越界的语义与计数**：K=6、9 的 m=K−1，唯一 >m 的指标

   （数据：beyond=0）。K=12 停机前恰有 1 次合法越界
   （s=11：ε=1/10 时 t=34 > 必要界 30）。
5. 守恒破缺方向（F_m 向下漂移，逐步恒等式的直接推论）与
   窗口内饱和现象维持原观察；"ε→0 与 t→∞ 不可交换"的精确
   表述：固定可观测量（自然停机时刻、停机态 U、首次越界时刻）
   分别研究 ε→0 与 t→∞ 极限；当前只有有限 ε 的精确/浮点数据，
   渐近常数未证。

## C2 网格相位：连续模型 + warp 网格

模型（按任务书 §4C2）：连续初态 CDF A(x)=2x−x²、XO CDF G 固定；
网格 φ(x)=(1−λ)x+λx²；格质量 p0_i=A 差分，**目标=格长**，
核 g_i=G 差分，加权指标 U_w=Σ(p_i−u_i)²/u_i（均匀网格时=U）。
一致性核验通过（非负、Σ=1、λ=0 归约 canonical）。自然停机检查
已加入：36 组中**无一组触发**（全部合法运行至 T=100）。

主发现（**36 个唯一 (K,λ) 配置**，39 条记录因 3 组重复；精确）：

1. **mod-6 字类不是 K 的内禀性质**：λ=1/4 下 K=15,16,17 从
   CYCLE 变 LOCK、K=12 从 LOCK 变周期字。σ 相位是强组织子
   （σ 大→LOCK 带、σ 中段→周期带）。
2. **措辞修正（R7）**：字类判据是**尾部 24 步短字匹配**，不是
   无限时间周期性证明；"σ 非完全分类"的两个相邻样本
   （σ=0.500 per=11 vs σ=0.513 per=1）只是**反例线索**——要
   否定"存在仅依赖 σ 的分类函数"需要**相同 σ 不同字类**的样本
   或解析论证，当前证据等级降为 [工作猜想方向]。
3. **早期停止对网格相位稳健**：36 组全部 argmin_Uw=2、驻留
   {m−1,m} 成立、无越界——长程字结构脆弱与早期停止稳健的
   解耦在测试范围内成立（有限配置，非全称）。
