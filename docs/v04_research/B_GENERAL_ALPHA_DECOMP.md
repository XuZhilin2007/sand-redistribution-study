## 2. 定理候选 B-D（一般 α 强化分解）

**命题。** 设从 t₀ 起选择驻留 {ℓ,m}（不要求周期字）。则对一切
t≥t₀ 与 i<m：

```math
p_{t,i}=\gamma(x_t)\,g_i+(1-\alpha)^{t-t_0}e_i,\qquad
e_i=p_{t_0,i}-\gamma(x_{t_0})g_i ,
```

后缀 i>m 冻结于 p_{0,i}，且

```math
U(p_t)=Q(x_t)+2z_t\Phi(x_t)+KE_2z_t^2,\qquad z_t=(1-\alpha)^{t-t_0},
```

其中系数装配与 v0.3.0 定理 E 的 L5 **逐字相同**（Q 二次、Φ 仿射、
E_2=Σe_i²、G₁/G₂/GE/E₁ 定义不变）——**装配公式不显含 α**：α 通过
进入时刻 t₀、进入状态 (x_{t₀},e_i) 进入。**（连续性限定，复核
I4 后补）**：进入状态"随 α 连续"仅在每个**已固定、已许可的选择
分片内部**成立；在 s₁ 等精确平局点，真实轨道与 U₂ 按左右分片
跳变（例：K=32 在 α₀=1/4 的 ‖p₂ᴿ−p₂ᴸ‖₁=43/1536），不得用跨支
连续性封口。

*逐支推导*（完整；A 支=M 从 c 出发，B 支=M 从 c−x 出发）。

A 支（s=m，M=αc，x′=(1−α)x+αcq）：

```math
c-x'=(1-\alpha)(c-x)+\alpha c(1-q)
\;\Rightarrow\;\gamma(x')=(1-\alpha)\gamma(x)+\alpha c,
```

```math
p'_i-\gamma(x')g_i=(1-\alpha)p_i+\alpha cg_i-
\bigl[(1-\alpha)\gamma(x)+\alpha c\bigr]g_i
=(1-\alpha)\bigl(p_i-\gamma(x)g_i\bigr). ✓
```

B 支（s=ℓ，M=α(c−x)，x′=x+α(c−x)q，c−x′=(c−x)(1−αq)）：

```math
\gamma(x')=\gamma(x)(1-\alpha q),
```

```math
p'_i-\gamma(x')g_i=(1-\alpha)p_i+(c-x)g_i
\Bigl[\alpha-\frac{1-\alpha q}{1-q}\Bigr]
=(1-\alpha)p_i-\frac{(1-\alpha)(c-x)}{1-q}g_i
=(1-\alpha)\bigl(p_i-\gamma(x)g_i\bigr). ✓
```

（用 α−(1−αq)/(1−q)=(α−1)/(1−α)… 即 −(1−α)/(1−q)。）

**机器验证** [已验证计算结果]：36 组 (K∈{9,10,11,12,29,65} ×
α∈{1/8,1/5,1/4,1/3,2/5,1/2})，(i) 分解逐分量精确相等（t 至
t₀+25）；(ii) 二次型在 t∈{t₀..t₀+8} 与真实 U 逐位相等——零失败。
α=1/4 时与 v0.3.0 已证版本一致（交叉核验）。

## 3. 停止充分条件原型（证书）

**定理候选 B-S。** 在 B-D 假设下，记 H(z)=H₂z²+H₁z+H₀，
H₂=KE₂−d²/A，H₁=2f−Bd/A，H₀=C−U(p_{t₀})−B²/(4A)（A,B,C,d,f 同
E 的 L5 装配）。若

- S1′：A>0；S2′：H₂>0；S3′：H′(1−α)≤0；S4′：H(1−α)≥0；
  且前缀支配 U(t)≥U(p_{t₀})（t<t₀，有限项），

则对一切 t≥t₀ 有 U(p_t)≥U(p_{t₀})：**t₀ 为全局最优停止时刻**。

*理由*：t≥t₀+1 时 z_t≤1−α；H 凸（S2′）且在 [0,1−α] 递减（S3′），
故 U−U(t₀)≥H(z)≥H(1−α)≥0；平方项由 S1′ 对一切实 x 非负。
α=1/4、t₀=2 时退化为 E 的 S1–S4。

**机器验证** [已验证计算结果]：cert_all=True 的 **13/36** 案例
（计数由 JSON 自动汇总复核，第一波误写 15/36）全部"t₀ 后无 dip"
（充分条件从未误判）；其余 23 例中 12 例确有 dip（含 K=9 α=1/5
在 t=3、K=9 α=1/3 在 t=2——**"进入即停"不一般最优**的精确证据），
另 11 例为证书偏保守（条件非必要，与 E 的有限差集
{9,10,11,16,17,23} 在 α=1/4 的表现一致）。验收门见 §4 R1 修复；
**结论的前置假设是驻留，canonical 范围由定理 A（T3′）提供**。

## 5. 推广障碍（诚实清单，R6 后修订）

1. B-S 是**逐点**证书：入口状态 (x_{t₀},e) 逐 (K,α) 计算。
   全 K、连续 α 区间的统一陈述需要 (i) 进入时刻 t\*(K,α)=2
   在区间上的一致性（选择字逐 α 分片常值，切换点代数）与
   (ii) 系数关于 (n,α) 的联合符号控制（阶段二主线，见
   A 文档 §6.5 与 STATUS）。
2. **驻留不再是障碍**（定理 A 承接，canonical 范围）；真正的
   无限量词在前缀比较（有限项多项式）与尾部 S 条件的
   连续 α 覆盖。
3. 加权二次损失 / 一般核族的推广：系数装配依赖 γ 仿射与 g 支撑
   截断（g_i=0, i>m）；泄漏核（C1）破坏后者，分解不直接适用。
