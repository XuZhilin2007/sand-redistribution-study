# 定理 T6：冻结分类器在原 α=1/4 设置下的全 K 一致性

> v0.2.0 正式收录，2026-10-07。范围与证据等级见[补充成果登记](XO_EXTENSION_REGISTRATION.md)，
> 独立审查来源见[补充审查记录](XO_EXTENSION_REVIEW.md)。实验室旧稿与修订历史在私人仓库保留。


## 1. 冻结分类器与定理

K≥6，H=10K。itinerary 为状态 t=0..H−1 的选择序列，共 H 项。
t* 是首次选择 {ℓ,m} 的时间，R_m 是末尾连续 m 的项数。
分类器按优先顺序：
1. R_m≥K：LOCK；
2. 否则，t* 存在且进入后集合恰为 {ℓ,m}：CYCLE；
3. 否则 OTHER。
实现来源：../experiments/s4_w1_s2_boundary_microscope/run_s2.py 的 classify_itinerary。

**T6**：所有整数 K≥6，在上述范围内，
K mod 6∈{0,1,2} iff LOCK；K mod 6∈{3,4,5} iff CYCLE；无 OTHER。
这是有限窗口分类器与已证长期二分之间的连接，不是新的周期性定理，
也不是对任意 α 的分类器普适性定理。

## 2. 依赖与记号

采用底本 S3 已入库的 T1–T5（α=1/4）：
h=1/K，r=K mod6，m=ceil(5K/6)，ℓ=m−1，b=m/K，
c=2b−b²，a=b(1−b)，q=(6−r)/(3K)，L=cq。
t*≤T=floor(81K/20)+1；从 t* 起选择持久于 {ℓ,m}。
进入后 x=p_m 满足 x'=(3/4)x+L/4（x>h），
x'=x+(c−x)q/4（x≤h）。范围 0≤x≤c。
T6 仅依赖底本 α=1/4 的定理，不需要推广后的 A。

## 3. 有效驻留界

### 3.1 初始下支

从任意 x₀≤h，下支 n 步后 c−x_n=(1−q/4)^n(c−x₀)。
为确保严格上穿 x_n>h，可选
N_B=floor[(4/q)h/(c−h)]+1。
Bernoulli 界 (1−z)^n≤1/(1+nz)，以及 N_B>(4/q)h/(c−h)，
保证 (1−q/4)^{N_B}c<c−h。这里保留严格比较，避免 x=h 仍属于下支的计数错误。
q≥1/(3K)，h/(c−h)≤(1/6)/(29/36)=6/29，
故 N_B≤72K/29+1。

### 3.2 经 m 进入的首个上支

CYCLE 类 λ=L/h≤80/81：
r=3 时 λ=c=1−((K−3)/(6K))²，在 K=9 最大为80/81；
r=4 时 λ≤(2/3)(99/100)；
r=5 时 λ≤(1/3)(120/121)。
每类 c 随同余类内 K 增加而递减（b=5/6+r/(6K) 递减，c=2b−b² 递增于 b）。
于是 h−L≥1/(81K)，c−L≤1。
81·9·(3/4)^27<1，且对于 K≥9，
[81(K+1)(3/4)^{3(K+1)}]/[81K(3/4)^{3K}]
=((K+1)/K)(27/64)≤15/32<1。
所以 81K(3/4)^{3K}<1，首个上支至多 U₁≤3K 轮后到达 x≤h。

### 3.3 后续上支

从下支上穿后 x₀≤h+L/4，故 x₀−L≤h−3L/4。
取 N_A=min{n≥1:(3/4)^n≤(h−L)/(h−3L/4)}。
λ≤80/81 给出比值≥1/21，而 (3/4)^11≤1/21，所以 N_A≤11。
该界只用于从下支着陆后开始的上支游程，不套用到未经下支的初始上支。

## 4. LOCK 侧

r∈{0,1,2} 时 L>h；上支不再离开。
初始下支项数 n'_B≤N_B，故
R_m=H−t*−n'_B
≥10K−(81K/20+1)−(72K/29+1)
=(2011/580)K−2≥K（K≥6）。
最小 K=6 即满足不等式；因此所有 LOCK 类均按冻结规则判 LOCK。
精确轨迹 K=6 的 t*=1、R_m=58 作为回归核对保留。

## 5. CYCLE 侧

CYCLE 类最小 K=9。
若经 ℓ 进入，先在 N_B 轮内上穿，再在 N_A 轮内到下支；
若经 m 进入，在 U₁ 轮内到下支。
由于 N_B≤72K/29+1≤3K（K≥9）及 U₁≤3K，
H 内必出现 A→B 选择切换，因为
t*+max(N_B,U₁)+11
≤(141/20)K+12<10K−1（K≥9）。
所有内部选择已被底本持久性排除，且两支都已出现。

这里“切换”指 x 从 >h 到 ≤h；恰落 h 时 discrepancy 可以保持相等，
不能把每一次 A→B 都称为严格 rebound。

经过这次切换，末尾 m 游程若非零，必始于后续下支上穿，
所以 R_m≤N_A≤11。
K≥12 时 11<K；K=10、11 分别有 N_A=2、1<K。
K=9：执行90项 exact rational scalar itinerary，可有限核算得 R_m=3<9。
验证脚本明确断言这一值，验收另用完整向量重算；
一个有限例外的精确核算是证明的一部分，不是对未测 K 的外推。

故所有 CYCLE 类 R_m<K，两支均出现，冻结规则判 CYCLE。证毕。

## 6. 驻留指纹：初始与后续分开

下穿着陆 x₀>(3h+L)/4。因此后续下支项数至多
N_B,post=min{n≥1:(1−q/4)^n[c−(3h+L)/4]≤c−h}。
此处可用 ≤，因为真实着陆点严格大于最坏起点。
不能把这条后续界用于初始下支。

代表值：K=9 的后续 A≤11、B≤1；K=10 的后续 A≤2、B≤1；
K=11 的后续 A≤1、B≤3。
实际初始下支与实际最大驻留值均由脚本计算并分别输出；
不从少数代表点外推所有 K 都恰好达到其界。

## 7. 验证与范围

verify_t6.py 的精确检查与本文修订后的公式一一对应：
LOCK 计数；3K 首上支界的基点及递减因子；CYCLE 链；
11轮后续上支界；K=9、10、11 有限例外；K=6..300 的295个分类实例。
抽查不承担“所有 K”的量词，该量词来自第3–5节的解析论证。
验收另外提取底本分类函数并以独立完整向量算法核对边界例与代表 K。

但 A 的无限时间结论仍双支切换。扩大 α 范围时需要另定有限窗口及判定条件。
