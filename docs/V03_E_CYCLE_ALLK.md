## 1. 陈述

**定理 E.** 对 canonical XO（$`\alpha=\tfrac14`$，精确算术，最小指标平局
规则）的每个 **CYCLE 类** $`K`$（$`K\bmod6\in\{3,4,5\}`$，$`K\ge9`$）：

```math
U(p_t)\ \ge\ U(p_2)\qquad\text{对一切整数 }t\ge0，
```

其中 $`U(p)=K\sum_i(p_i-\tfrac1K)^2`$。结合定理 B-lock（LOCK 全类）：
**canonical 全部 $`K\ge6`$：两轮最优停止成立**（$`K=6`$：$`t_*=1`$ 但
$`t_{\rm off}=2`$，已登记）。表述纪律：本定理只断言 $`t=2`$ 为**最优**
停止时刻（$`U(p_t)\ge U(p_2)`$），不断言唯一或最早最优，也不断言 $`U`$
随时间单调；CYCLE 状态为渐近周期（选择序列最终精确周期）。

## 3. 证明链（每一环精确）

**L1（前缀）.** $`s_0=\lfloor K/2\rfloor`$（$`D_0=x(1-x)`$）；$`s_1`$ 闭式
$`\lfloor(41K+31)/64\rfloor`$（偶）/ $`\lfloor(41K+26)/64\rfloor`$（奇）对
一切 $`K\ge33`$ 成立（两峰论证只依赖奇偶）；$`K<33`$ 重放（例外
$`K=10`$：$`s_1=7`$，在有限差集内经 D 证书覆盖）。

**L2（进入）.** `lemma_t2_cycle`：$`K\ge33`$ 时 $`t=2`$ 的 $`D_2`$ 格点
argmax $`\in\{\ell,m\}`$——锚点为 $`D_{2,m-1}`$（band-3 顶箱；CYCLE 的
$`b(1-b)`$ 锚可低于 $`1/8`$）；奇 $`K`$ 的 $`M_0\ge M(33)`$。故 $`t_*=2`$；
$`K<33`$ 重放。

**L3（驻留）.** 从首边界选择起持久于 $`\{\ell,m\}`$（定理 B 第 3 条 /
T3 的 canonical 情形；重放核验）。

**L4（加强版 D-decomp；只需两支驻留）.** 对 $`t\ge2`$、$`i<m`$：
$`p_{t,i}=\gamma(x_t)g_i+(\tfrac34)^{t-2}e_i`$（B 支 respray
$`\tfrac{c-x}4`$ 与 $`\gamma`$ 跳变精确相消；A 支同理）。独立实现逐
$`(t,i)`$ 核验。
这里 $`\gamma(x)=(c-x)/(1-q)`$，
$`e_i=p_{2,i}-\gamma(x_2)g_i`$，且 $`i>m`$ 的后缀冻结于 $`p_{0,i}`$。

**L5（二次型，修正恒等式）.**

```math
U(p_t)=Q(x_t)+2z_t\Phi(x_t)+KE_2z_t^2,\qquad z_t=\Bigl(\tfrac34\Bigr)^{t-2},
```

$`Q(x)=Ax^2+Bx+C`$、$`\Phi(x)=dx+f`$（$`d`$ 为 $`\Phi`$ 的 $`x`$ 系数）。
定义 $`E_2=\sum_{i<m}e_i^2`$、$`GE=\sum_{i<m}g_ie_i`$、
$`E_1=\sum_{i<m}e_i`$，则 $`\Phi(x)=K\gamma(x)GE-E_1`$，以及

```math
Q(x)=K\sum_{i<m}\bigl(\gamma(x)g_i-\tfrac1K\bigr)^2
+K\bigl(x-\tfrac1K\bigr)^2
+K\sum_{i>m}\bigl(p_{0,i}-\tfrac1K\bigr)^2.
```

生成器在每子族 3 个 $`u`$ 锚点对 $`t\in\{2,3\}`$ 做**直接回代**（重建
二次型 = 真实 $`U`$，逐项精确相等）；独立实现另在全部采样 K 上对
$`t\in\{2,3,4\}`$ 回代。

**L6（配方路线；Owner 给出并预检）.** 令 $`E=KE_2`$，写

```math
U-U_2=Ax^2+Bx+(C-U_2)+2z(dx+f)+Ez^2
=A\Bigl(x+\tfrac{B+2dz}{2A}\Bigr)^2+H(z),
```

```math
H(z)=\Bigl(E-\tfrac{d^2}A\Bigr)z^2+2\Bigl(f-\tfrac{Bd}{2A}\Bigr)z+
\Bigl(C-U_2-\tfrac{B^2}{4A}\Bigr).
```

断言（全部 RF 平移证书，绑定调用方起点/严格性）：
**S1** $`A>0`$；**S2** $`H_2:=E-\tfrac{d^2}A>0`$；**S3** $`-H'(\tfrac34)>0`$
（$`H'=2H_2z+H_1`$，$`H_1=2f-\tfrac{Bd}{A}`$）；**S4** $`H(\tfrac34)\ge0`$。
则：S1 使平方项对**一切实数 $`x`$** 非负（不再需要可达区间）；S2+S3
使 $`H`$ 在 $`[0,\tfrac34]`$ 严格递减，故 $`t\ge3`$（$`z\le\tfrac34`$）时

```math
U-U_2\ \ge\ H(z)\ \ge\ H(\tfrac34)\ \ge\ 0 .
```

$`t=2`$：$`z=1`$，$`U(p_2)=Q(x_2)+2\Phi(x_2)+KE_2`$ 恒等（锚点）；$`t\in\{0,1\}`$：
C0a/C0b。$`\square`$
