## 1. 问题与定义

均匀度指标：$`U(p)=K\sum_{i}\bigl(p_i-\tfrac1K\bigr)^2`$（本仓 U_density；
$`U=0\iff`$ 完全均匀）。停止问题：操作者逐轮观察状态并须在某个有限时刻不可逆
地停止；目标是使 $`U(p_{t_{\rm stop}})`$ 最小。**离线最优**
$`V_{\rm off}=\inf_t U(p_t)`$，$`t_{\rm off}=\arg\min_t U(p_t)`$。
观测量分层：完整质量向量 $`p_t`$ 可观测时一切均可计算；单点 $`(s_t,d_t)`$
**不**足以决定 $`U`$（例：$`K=7`$ 的 $`t=2,3`$ 均有 $`s_t=6`$、$`d_t=\tfrac6{49}`$
但 $`p_t`$ 与 $`U`$ 不同）——每条停止规则需单独声明其所需观测量。

## 2. 发现（精确验证于全部受检格点）

**命题 D（候选）。** 对 canonical XO（$`\alpha=\tfrac14`$）的每个受检
$`K\in\{6..203\}\cup\{300,600,999,1000,1001\}`$：

```math
t_{\rm off}=2\quad\text{且}\quad
\frac{U(p_2)}{U_{\rm asym}}\in[0.344,\ 0.448],
```

其中 $`U_{\rm asym}`$：LOCK 类取 $`U(p_\infty)`$（显式极限点）；CYCLE 类取
**真渐近周期轨道**（逐相位精确重建，见 §4）全 $`n`$ 个相位的精确最小值。即：
**过程在恰两轮后达到历史最均匀状态（对 $`K\ge7`$ 即边界进入时刻 $`t_*`$），
此后各轮的 $`U`$ 均不低于 $`U(p_2)`$，受检格点的渐近指标为
$`U(p_2)`$ 的约 2.2–2.9 倍。**

**在线规则（限定陈述）。** "在首次边界选择时停"与离线最优在全部受检
$`K\ge7`$ 一致；**$`K=6`$ 是已证例外**（$`t_*=1`$ 但 $`t_{\rm off}=2`$，
$`U(p_1)=\tfrac{2339}{13824}>U(p_2)=\tfrac{335}{2304}`$）。对固定 canonical
设置，"执行恰两轮"本身就是与离线最优一致的在线规则；边界检测是否优于
固定轮数，需在更广初态/参数范围内研究（开放）。

## 3. LOCK 类的精确结构（证明骨架 + 逐 K 证书）

从永久选择 $`m`$ 的状态时刻 $`t_{\rm lock}`$ 起，
$`p_{t}=p_\infty+\rho^{\,\tau}e`$（$`\tau=t-t_{\rm lock}`$，
$`\rho=\tfrac34`$，$`e=p_{t_{\rm lock}}-p_\infty`$）。代入 $`U`$：

```math
\boxed{\;U(t)-U_\infty=2\rho^{\,\tau}S'+\rho^{2\tau}E'\;},\qquad
S'=K\sum_i e_i\bigl(p_{\infty,i}-\tfrac1K\bigr),\quad
E'=K\sum_i e_i^2 .
```

（本实验在 $`\tau\in\{1,5,25,100\}`$ 逐点精确核验该恒等式。）全部受检 LOCK
格点 $`S'<0`$：$`U`$ 从下方趋近 $`U_\infty`$，有限时间最优存在且在窗口内为
$`t=2`$。**尾部精确证书**：对 $`\tau`$ 超出窗口，$`U-U_\infty=q(u)=2S'u+E'u^2`$
（$`u=\rho^\tau\le u_{\rm cap}`$），其最小值只能在 $`u_{\rm cap}`$ 或顶点
$`u^*=-S'/E'`$（若 $`\le u_{\rm cap}`$）取得——两个显式候选的精确比较给出
$`U(2)\le U_\infty+\min_{\rm tail}q`$，即 $`t=2`$ 支配整个无穷尾部。

## 4. CYCLE 类的精确结构（逐 K 证书）

**真周期轨道的精确重建**（不用标量外推——完整剖面同时含边界标量与内部
坐标两种衰减率，不能统一外推）：(i) 由字 $`w`$ 的仿射合成解出边界坐标的
精确周期点与周期轨道（周期收缩率 $`\Lambda=(\tfrac34)^{\#A}\beta^{\#B}`$，
如 $`K=9`$ 的 $`\Lambda=\tfrac{688905}{16777216}`$）；(ii) 内部坐标
（每步恰按 $`\tfrac34`$ 收缩、被周期驱动的仿射递推）的周期解用**几何级数
闭式**逐相位精确求出：
$`D^{(\phi)}_j=\tfrac{1}{1-(3/4)^n}\sum_{i=0}^{n-1}(\tfrac34)^i
b_j(\phi-1-i)`$，$`b_j`$ 由周期性 $`F_s`$（A 步 $`=c`$，B 步 $`=c-x^{(\phi)}`$）
给出；(iii) **单步回代验证**：对重建剖面上执行字的一步精确更新，必须

**无穷尾部的严格覆盖**（ Owner 审查 P1-2 修复）：窗口末端 $`t_0`$ 处的
精确偏差（$`\delta_x`$、$`\delta_{\rm int}`$）出发，三角衰减包络给出对一切
$`t\ge t_0`$：$`|x_t-x^*_{\rm phase}|\le\delta_x\mu^{t-t_0}`$
（$`\mu=\max(\tfrac34,\beta)<1`$）、内部差 $`\le(\tfrac34)^{t-t_0}\delta_{\rm int}
+\tfrac{\delta_x}4(t-t_0)\mu^{t-t_0-1}`$（单向耦合，B 步注入 $`\le\tfrac14|\delta_x|`$）；
单峰函数 $`g(\Delta)=(\alpha+\beta_c\Delta)\mu^\Delta`$ 的全局最大由精确扫描
取得，从而 $`\|p_t-q_{\rm phase}\|_2\le\lceil\sqrt K\rceil\,g_{\max}`$，且
令 $`Q_2=\|q-h\|_2^2`$、$`r_t=p_t-q`$。直接展开并用 Cauchy–Schwarz：

```math
U(p_t)=K\bigl(Q_2+2\langle q-h,r_t\rangle+\|r_t\|_2^2\bigr)
\ \ge\ KQ_2-2K\sqrt{Q_2}D
\ \ge\ KQ_2-K(1+Q_2)D.
```

这里 $`2\sqrt{Q_2}\le1+Q_2`$，不需要对可能为负的反三角下界平方。
证书：$`U(2)\le\min_\phi[\text{该下界}]`$
且窗口内 $`\arg\min=2`$。无限时间最优性由此**被覆盖**（不只渐近值比较）。

## 6. 前缀分解（WP2 已验证命题，Owner 提出的降维）

**命题 D-decomp（精确，两支皆证）。** 设从 $`t_0`$ 起选择始终驻留于
$`\{\ell,m\}`$；不要求固定周期字或相位。则对一切 $`t\ge t_0`$ 与 $`i<m`$：

```math
p_{t,i}=\frac{c-x_t}{1-q}\,g_i+\Bigl(\tfrac34\Bigr)^{t-t_0}e_i,
\qquad e_i:=p_{t_0,i}-\frac{c-x_{t_0}}{1-q}\,g_i,
```

边界格为 $`x_t=p_{t,m}`$，后缀 $`i>m`$ 冻结于 $`p_{0,i}`$。

*证明（两支逐一代入）。* A 支（$`s=m`$，$`M=c/4`$，
$`x'=\tfrac34x+\tfrac{cq}{4}`$）：

```math
p'_i-\tfrac{c-x'}{1-q}g_i
=\tfrac34p_i+\tfrac c4g_i-g_i\Bigl[\tfrac{c(1-q/4)-\tfrac34x}{1-q}\Bigr]
=\tfrac34p_i+\tfrac34\tfrac{x-c}{1-q}g_i\ \checkmark
```

（合并喷撒项与中括号项，因
$`\tfrac c4-\tfrac{c(1-q/4)-(3/4)x}{1-q}
=\tfrac{(3/4)(x-c)}{1-q}`$）。B 支（$`s=\ell`$，$`M=\tfrac{c-x}{4}`$，
$`x'=x+\tfrac{(c-x)q}{4}`$，$`c-x'=(c-x)(1-\tfrac q4)`$）：

```math
p'_i-\tfrac{c-x'}{1-q}g_i
=\tfrac34p_i+(c-x)g_i\Bigl[\tfrac14-\tfrac{1-q/4}{1-q}\Bigr]
=\tfrac34p_i-\tfrac34\,\tfrac{c-x}{1-q}g_i\ \checkmark
```

（$`\tfrac14-\tfrac{1-q/4}{1-q}=\tfrac{(1-q)-(4-q)}{4(1-q)}=-\tfrac34\cdot
\tfrac1{1-q}`$）。两支均使偏差 $`p_{t,i}-\tfrac{c-x_t}{1-q}g_i`$ 按
$`\tfrac34`$ 递缩，归纳完成。已在 $`K\in\{9,10,11,21,65,99\}`$（含 B 步的
窗口 $`\Delta t\in\{1,2,5,13,40\}`$）逐点精确核验。$`\square`$

**推论（U 的降维）。** 代入 $`U`$：$`U(p_t)`$ 是 $`(x_t,\rho_t)`$ 的显式
二次型（$`\rho_t=(3/4)^{t-t_0}`$），系数为 $`K`$ 的有理函数（$`\sum g_i(\cdot)`$、
$`\sum e_i(\cdot)`$、$`\sum e_i^2`$、交叉项、冻结后缀项）。全 $`K`$ 定理需要控制
进入与整个暂态，而不只比较周期轨道上的极限值。
**当前状态：已由 B-lock 与修复后的 E 闭合**：$`K\ge7`$ 时 $`t_*=2`$，
LOCK 用永久驻留后的二次式，CYCLE 用对一切实数 $`x`$ 成立的配方下界，
六个有限例外由 D 的全时间证书处理；$`K=6`$ 另有点证书。

## 7. 与既有结构的关系

$`K\ge7`$ 时 $`t_{\rm off}=t_*=2`$ 揭示了一个此前未登记的层面：边界进入既是动力学的分水岭
（T2/T3），也是均匀度的全局峰值时刻。长期动力学（T7 的周期轨道）不是
"更均匀"的方向——反馈把质量持续推向 $`c\cdot g`$ 剖面（LOCK）或周期集
（CYCLE），二者都比进入时刻的状态更不均匀。原问题"什么时候该停止干预"
在 canonical 设置下有一个干净的反直觉答案：**执行恰两轮**。
$`K=6`$ 的首次边界进入为 $`t_*=1`$，最优停止仍为 $`t=2`$。
