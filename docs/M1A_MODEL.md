# M1A 模型定义：自适应扫掠边界（最小反馈模型）

> 状态：M1A canonical 定义（2026-09-18）；首个 state-dependent feedback 模型
>
> 实验：[M1A_REPORT.md](../experiments/m1a_adaptive_boundary/M1A_REPORT.md)；前置：[M0_MODEL.md](M0_MODEL.md)、[M0_GENERAL_Q.md](M0_GENERAL_Q.md)
>
> 证据等级声明：M1A 的 adaptive rule 是 **模型假设（Model Assumption）**——它只是"人观察当前沙面再决定扫到哪里"这一真实观察的最小数学抽象，**不是**真实人类视觉停止规则。本文所有结论只对 M1A 模型成立。

## 0. M1A 相对 M0 只改变一件事

M0 的扫掠区域永远固定（`x < 0.5`）。M1A 让它每轮由当前状态决定。其余一切不变：一维等面积坐标、K=100、uniform 目标、q_near 重泼、alpha 比例移除、同一 primary 指标、deterministic 期望质量为主。

# 第 1 层：直觉解释（不需要高数）

## 1.1 操作者怎么看、怎么扫、怎么停

把"从脚边往前看到 x 为止"的这段沙与"如果完全均匀这段应该有多少沙"比较，差值叫**累计过剩** `D(x)`：

- `D(x) > 0`：这一段沙偏多（从脚边到 x 为止累计多了）；
- `D(x) ≤ 0`：这一段不多。

M1A 每轮的规则只有三句话：

1. **看**：找出累计过剩最大的位置——"到哪儿为止多得最厉害"；
2. **扫**：如果最大过剩是正的，就把脚边到那里的沙按比例 alpha 收走、按原来的 q 重新泼出；
3. **停**：如果**任何**一段都不比均匀多（所有前缀的累计过剩 ≤ 0），说明近侧已经没有明显过剩——模型内自然停止。

这不是说"人就是这么想的"，而是把"根据当前状态移动扫掠区"压缩到不能再压缩的数学规则。

## 1.2 运行起来是什么样（q_near, alpha=0.25, 100 轮）

- **第一轮与 M0 一模一样**：初始 q_near 的累计过剩是 `x(1−x)`，峰值恰在 x=0.5，所以第一轮扫掠区就是 [0, 0.5]，得到的状态与 M0 第一轮完全相同（逐位验证）。
- **从第二轮起分岔**：扫掠后远端接收了重泼的沙，过剩峰值移到 0.58（有闭式公式，见附录）——边界开始跟随状态移动。之后边界**来回振荡**（100 轮内最小 0.21、最大 0.97），不再有任何固定路线。
- **均匀度持续缓慢改善**：U 从 3.33×10⁻³ 降到 t=98 的 1.49×10⁻⁴（M0 最佳是 1.68×10⁻³，M1A 低 11 倍），到 100 轮仍在波动，没有出现 M0 那种"第 4 轮最佳然后恶化到比初始还差"的过冲。
- **近区不再被掏空**：固定物理近区 [0, 0.5] 的沙量全程保持在 0.501–0.75（理想值 0.5！），而 M0 到 100 轮塌缩到 0.0012。**过度修正被自适应边界消除了。**
- **但是它不停**：累计过剩从 0.25 一路波动下降到 ≈0.05，始终为正——因为重泼分布 q_near 把 75% 的沙送回 x<0.5，而均匀份额只有 50%：每轮扫掠都在近侧重新制造新的过剩。**在 q_near 下 M1A 在 100 轮内不会自然停止**（对照：均匀与远偏分布第一步就停）。
- **边界选择永远是"近平局"**：每一轮，最优前缀与第二优前缀的过剩差都小于 0.005（中位数 0.0001）——状态并不指定一个唯一正确的扫掠点，很多选择几乎一样好。这解释了边界为何大幅振荡，也说明该规则对噪声天然敏感（留给未来"感知尺度"研究，本轮不修补）。

## 1.3 直觉总结

自适应边界治好了 M0 的两个病（固定区域的过冲与掏空），代价是引进一个新现象：只要重泼分布仍然偏向近侧，"近侧过剩"就永远会被重新制造出来，模型于是永远在扫——它变得更均匀，但从不"满意"。

# 第 2 层：Mathematical Definition

## 2.1 状态与累计过剩

第 t 轮 bin 质量 `m_i(t)`（i = 1..K，K=100，Σm = 1）。定义前缀累计过剩：

```text
D_t(j) = Σ_{i=1}^{j} m_i(t) − j/K,      j = 1, …, K
```

性质（精确）：

- `D_t(K) = 0` 恒成立（总质量为 1），故 `D_max(t) ≡ max_j D_t(j) ≥ 0`；
- `D_max(t) = 0` 当且仅当 `F_t(x) ≤ x` 对一切 x 成立——即状态的 CDF 被均匀 CDF 处处支配（每个前缀都不过剩）。**这就是停止状态的精确刻画**；注意它不蕴含 U=0（远端可以过满）。

## 2.2 自适应边界与更新规则

```text
j_t = argmax_j D_t(j)（并列取最小 j，确定性的）
a_t = j_t / K
```

若 `D_max(t) > tol`（tol = 10⁻¹²，数学条件 D_max ≤ 0 的数值实现，冻结不调）：本轮扫掠前缀 [0, a_t]：

```text
m_i(t+1) = (1 − alpha)·m_i(t) + R·q_i     (i ≤ j_t)
m_i(t+1) = m_i(t) + R·q_i                 (i > j_t)
R = alpha · Σ_{i≤j_t} m_i(t)
```

（前缀各 bin 被移除 alpha 份额，移除总量 R 按固定 q 泼回整个 [0,1]，前缀同样接收自己的份额。）若 `D_max(t) ≤ tol`：本轮不扫掠（自然停止），状态冻结。每轮重新计算 D_t 与 a_t。总质量守恒、质量非负（已测试）。

## 2.3 可严格推导的性质（Model-derived Mathematical Result）

1. **首轮与 M0 重合**：初始状态为 q_near 时 `D_0(x) = F_q(x) − x = x(1−x)`，`argmax` 在 x=1/2，故 `a_0 = 0.5` 精确成立；因此 M1A 的第一次更新与 M0（a=0.5）的第一次更新完全相同（数值逐位一致）。
2. **第二个决策的闭式**：一次 M0 型更新后（近区幅度 `z = 1 − alpha(1−Q)`，远区幅度 `λ = (1−Qz)/Q_f`，Q=0.75），x > 0.5 段的过剩为 `D_1(x) = λ(2x−x²) − x + Q(z−λ)`，其最大点在

   ```text
   x* = (2λ − 1) / (2λ)
   ```

   alpha = {0.10, 0.25, 0.50, 1.00} 给出 x* = {0.535, 0.579, 0.636, 0.714} → 离散边界 a_1 = {0.53, 0.58, 0.64, 0.71}（随 alpha 单调右移，全部与模拟逐位吻合）。
3. **边界之外过剩只减不增**：对 x > a_t，

   ```text
   D_{t+1}(x) = D_t(x) − alpha·F_t(a_t)·(1 − F_q(x)) ≤ D_t(x)
   ```

   即一次扫掠不可能在自身边界之外制造新的累计过剩；过剩的再创造只能发生在被扫前缀内部（重泼回填）。这解释了边界的振荡：扫过的区域过剩衰减，未扫区域的相对过剩随后成为新的 argmax。
4. **time-rescaling 恰好在第二个决策处破坏**：a_t 是状态的函数，而状态从第一轮起就依赖 alpha（与 M0 相同），于是第二个决策 a_1 依赖 alpha——扫掠算子本身随 alpha 改变。M0 的"同一状态路径、不同速度"不再成立：不同 alpha 的 M1A 是**不同的过程**（轨迹分岔于 t=1 决策 / t=2 状态）。

## 2.4 停止状态的必要条件与不可达性

停止要求 `F_t(x) ≤ x` 对一切 x。但重泼分布 q_near 满足 `F_q(0.5) = 0.75 > 0.5`：每次扫掠都把被移除质量的 75% 送回 x < 0.5，而那里的均匀份额是 50%——**重泼在结构上持续再造近侧累计过剩**。因此对 q_near，M1A 在 T_max = 100 内不停止（D_max 从 0.25 波动衰减到 ≈0.05，且非单调：100 轮中有 34 次回升，最大一次 0.016→0.067）。这不是数值问题，而是"近偏重泼 + 前缀停止判据"的结构性张力。

## 2.5 无闭式解的说明

M0 的闭式来自"固定线性算子反复作用"。M1A 的算子每轮由状态决定（分段线性、切换式），不存在已知简单闭式；上文 2.3 的四条性质是本轮能严格推出的全部结构。**不为了公式漂亮而修改模型**——进入无闭式的反馈过程正是 M1A 的目的。

## 2.6 术语注记（2026-09-18，M1A.1）

`D_max(t) = max_j [F_t(j/K) − j/K]` 在数学上等于针对 Uniform(0,1) 目标的 **one-sided Kolmogorov–Smirnov functional** `sup_x [F_t(x) − x]`（阶梯 CDF 的上确界恰在 bin 右端点取到，故离散 max 精确等于连续 sup；证明与核验见 [M1A_LONG_HORIZON.md](M1A_LONG_HORIZON.md)）。这只是函数形式相同的术语联系：M1A 不做假设检验，无 novelty 声明。

另：M1A.1 诊断修正了本文档相关实验观察的时间尺度——exact stopping 在 q_near 下可达（K=100 时 t=699），"100 轮内不停止"只是预算表象；边界振荡是停止前瞬态。详见 [M1A_LONG_HORIZON.md](M1A_LONG_HORIZON.md)。
