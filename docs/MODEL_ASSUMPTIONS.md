# 模型假设台账（Model Assumptions Register）

> 状态：临时假设清单；当前没有被确认的真实参数集
>
> 基线日期：2026-09-13

## 1. 使用原则

本文件集中管理为了让模拟能够运行而引入的规则。写入这里并不表示假设正确，只表示它已被识别、能够被讨论和检验。

每项假设都应记录：

- 为什么需要；
- 有什么现实依据；
- 当前可信度；
- 是否需要敏感性分析；
- 是否需要真实实验校准；
- 可能影响哪些输出。

可信度评价针对“该假设作为真实过程近似是否可信”，不针对它作为计算示例是否方便。

## 2. 当前总体状态

目前没有 canonical model，也没有一组被批准为“真实参数”的设定。历史 raw runs 混合使用了不同的回收策略、密度指标、阈值和运行长度，不能把它们合并成一份统一参数表。

下表中的具体例子用于识别历史假设，不是后续 baseline 必须沿用的默认值。

## 4. 高影响临时假设：`r = U^2`

设 `U` 为 `[0, 1]` 上均匀随机变量，早期脚本用 `r = U^2` 生成归一化径向位置。由于平方会把较多样本压向零，它能方便地制造“近处更容易落”的现象。

这条规则必须明确标记为：

> **模型假设 / 高影响临时假设（Model Assumption / High-impact Provisional Assumption）**

它不是测量结果，也不是由沙粒动力学推导出的定律。它会直接决定：

1. 初始分布的近密远疏程度；
2. 每轮回收后向外重新分配的速度；
3. 有限最佳或近最佳状态出现的轮次；
4. 近区是否容易被掏空；
5. 远区是否会积累；
6. 停止阈值看到的密度信号；
7. 最终空间结构及其对均匀度指标的表现。

因此，任何依赖该规则得到的“最佳第几轮”“最佳回收比例”“最佳扫线”或“最佳阈值”，都只能解释为该临时模型内部的探索结果。

后续优先比较：

- `r = U`；
- `r = U^a` 的多个 `a`；
- Beta 分布族（Beta family）；
- 其他能控制近远偏置且参数可解释的单调径向分布。

比较目标不是从模拟中“找真实参数”，而是检验有限最佳状态是否依赖 `r = U^2` 这一特殊选择。

## 5. 已知模型失配

### 5.1 固定扫线

固定扫线会在每轮持续把某个半径内的沙向外搬运，即使该区域已不再明显过密。历史探索中它容易把近区清空，产生不自然空洞。因此它适合作为会过度操作的对照模型，不应被称为真实扫沙规则。

### 5.2 最近固定比例回收

最近比例模型每轮强制回收固定质量，无法表示“没有值得修正的区域就停止”，也无法处理独立的中远区密集块。它最多是可复现的 toy baseline。

### 5.3 机械热点阈值与狭窄扇区

狭窄、机械的局部扇区扫回可能制造稀疏沟槽；对所有轻微偏差继续响应会导致过度修正。现实操作者的视觉容忍度、路径宽度和判断迟滞尚未建模。

### 5.4 单一尺度指标

硬网格标准差会随网格分辨率变化，单一平滑尺度也可能忽略更细或更粗结构。“看起来均匀”不能由一个未校准尺度自动代表。

## 6. 假设更新规则

未来修改假设时：

1. 不覆盖本文件中的历史判断；在研究日志追加日期、原因和证据。
2. 给每次正式实验保存完整参数、随机种子、代码 commit 和指标定义。
3. 同一实验中只改变预先声明的因素，避免把多个策略变化误称为参数敏感性。
4. 若假设由现实照片或测量校准，仍需记录采集条件、误差和适用范围。
5. 只有通过明确复现的模拟结果才能使用“已验证模拟结果”标签；现实数据支持与文献支持须另行标注。
