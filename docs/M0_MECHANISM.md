# M0 机制解释：为什么第 4–5 轮最佳，以及 alpha 到底改变了什么

> 状态：canonical model M0 的机制分析文档（2026-09-18）
>
> 配套实验：[M0.1 报告](../experiments/m0_1_mechanism/M0_1_REPORT.md)；模型定义：[M0_MODEL.md](M0_MODEL.md)
>
> 证据等级声明：本文第 1 层是解释，第 2 层（数学附录）的全部等式都从 M0 定义精确推导，并在 `src/sand_m0/mechanism.py`、`tests/test_m0_mechanism.py` 与 M0.1 实验中独立数值核验。所有结论只对 M0 模型成立。本文不产生任何真实沙坑结论。

本文回答两个问题：

1. 为什么 EXP-M0-A 在第 4–5 轮达到最佳均匀状态？
2. 改变 correction strength `alpha`，改变的是"最佳状态本身"，还是"多少轮到达"？

答案（先给结论，后文分层论证）：

- 最佳轮次由一条**与 alpha 无关的状态路径**决定：deterministic M0-A 的整个轨迹由**一个数字** `z` 描述，均匀度误差 `U` 是 `z` 的**精确二次函数**，最低点在 `z* = 3/4`（连续版本精确成立；离散 100-bin 实现为 `z* = 0.749972`，修正 −2.8×10⁻⁵）。
- `alpha` 只决定 `z` 每轮乘以多少（`×(1 − alpha/4)`），即**只改变沿这条路径前进的速度**。baseline `alpha=0.25` 下 `z=(15/16)^t`，`z=3/4` 对应 `t ≈ 4.46`，所以第 4、5 轮夹住最优点、形成浅平台。

# 第 1 层：直觉解释（不需要微积分）

## 1.1 每轮只做两件"不改变形状"的事

M0-A 每一轮对沙面做的事，可以拆成两个动作：

1. **近区等比例缩小**：近区（x < 0.5）每一格都被拿走**同样比例**（alpha）的沙。每格都按同一比例减少，就像把一张图片整体调暗——图案不变，只是整体变淡。
2. **按原形状补回**：被拿走的沙重新泼出时，仍然按同一条 `q_near` 规律落点。泼回近区的部分，每一格得到的沙正比于 `q` 在该格的概率——而近区当前的形状恰好就是 `q` 的形状（只是整体幅度变淡了）。**按同样的形状加东西，形状不会变。**

两个动作都不改变"图案"，只改变幅度。所以近区内部的分布形状**永远不变**，远区同理（远区不回收、只接收 `q` 形状的补充，远区质量从一开始就是 `q` 的形状，加法不改变形状）。

**结论：M0-A 的沙面图案从第 0 轮到第 30 轮从未改变过，变化的只有两区的"亮度"。**

## 1.2 一个数字讲完全局：z = 近区还剩几成

既然图案不变，整个沙面只需要两个数字描述：近区幅度、远区幅度。而质量守恒把这两个数拴在一起，所以**实际上只剩一个数字**：

```text
z = 近区沙量占初始的比例 = (15/16)^t   （baseline alpha=0.25）
```

近区沙量随轮次的变化（每一轮净损失 1/16 = 6.25%）：

```text
75% → 70.3% → 65.9% → 61.8% → 57.9% → 54.3% → 50.9% → 47.7% → …
 t=0    t=1     t=2     t=3     t=4     t=5     t=6     t=7
```

- **近区**：形状 = 原始 `q` 形状 × `z`；
- **远区**：形状 = 原始 `q` 形状 × `(4 − 3z)`。

远区为什么是 `(4 − 3z)`？因为近区每让出一份质量，远区就要接收这一份；但 `q` 的质量只有 25% 落在远区，所以远区每一格的补充量是近区每格减少量的 **3 倍**（75/25 = 3 的杠杆）。z 从 1 降到 0 时，远区幅度从 1 涨到 4。

## 1.3 为什么最佳轮次是第 4–5 轮

均匀度误差 `U` 是"每个格子实际占比与理想值 1% 之差的平方和"。它可以看成两笔账之和：

- **近区的账**：近区各格误差的平方和。它自己最舒服的位置在 `z ≈ 0.64`（把近区平均密度恰好调到 1% 附近）；
- **远区的账**：远区各格误差的平方和。它自己最舒服的位置在 `z ≈ 0.83`（远区形状偏向中段，压得太低反而让密的那头过头）。

总误差是两条抛物线之和，最低点在两个"各自最舒服点"之间，按两条抛物线的**陡峭程度**加权平均：

```text
z* ≈ (0.01167 × 0.643 + 0.01500 × 0.833) / (0.01167 + 0.01500) ≈ 0.750
```

（这两个"陡峭度"就是 `q` 形状在近区/远区的集中度 `S_near : S_far = 7 : 1`，连续版本下精确给出 `z* = 12/(7+9) = 3/4`。）

`z* = 3/4` 意味着最佳状态出现在**近区沙量还剩约 56%** 的时刻（0.75 × 0.75 = 56.25%）——不是"近区恰好一半"（那对应 z = 2/3，是无形状误差的理想化情形）。远区的形状误差随幅度一起上涨，所以最优点来得更早。

最后换算成轮次：`z = (15/16)^t = 0.75` 解出 `t ≈ 4.46`。离散轮次只能取整数，第 4 轮（z=0.7725）和第 5 轮（z=0.7242）**恰好从两侧夹住** z*=0.75；第 4 轮离得更近一点，所以 U(4) < U(5)，但两者只差 0.25%——这就是 M0 报告里观察到的"t=4 / t=5 浅平台"的来源。

## 1.4 alpha 改变的是速度，不是路线

`z` 每轮乘以的因子是 `(1 − alpha/4)`：

| alpha | 每轮因子 | 走到 z≈0.75 需要 | 理论 t* | 实际最佳轮 |
|---|---|---|---|---|
| 0（边界） | ×1 | 永远到不了（不动） | — | 无（状态不变） |
| 0.10 | ×0.975 | 约 11–12 轮 | 11.36 | 11 |
| 0.25 | ×0.9375 | 约 4.5 轮 | 4.46 | 4 |
| 0.50 | ×0.875 | 约 2 轮 | 2.15 | 2 |
| 0.75 | ×0.8125 | 约 1.4 轮 | 1.39 | 1 |
| 1.00（边界） | ×0.75 | 1 轮 | 1.00 | 1 |

**同一条路，不同的速度。** 把横轴从"轮次 t"换成"系统走到哪里（z）"，所有 alpha 的 U 曲线**精确重合**（浮点误差 ~10⁻¹⁷ 量级，见 M0.1 实验）。极端例子：alpha=1 时每轮 z × 0.75，第 1 轮就精确落在 z=0.75 上——一步到达连续最优；alpha=0.75 的 z 网格（0.8125, 0.660, …）跳过了 0.75，所以它"能停下的最好状态"离理论最优最远（差 1.0×10⁻⁴）。

**"底层最佳状态相同"与"离散操作实际能达到的最佳状态相同"是两个不同的命题**：前者对所有 alpha 严格成立；后者依赖轮次离散化，随 alpha 略有差异。

# 第 2 层：数学附录（正式推导与数值核验）

## 2.1 记号与初始近区质量

`q(x) = 2(1−x)`，CDF 为 `F(x) = 2x − x²`。初始近区质量：

```text
Q = ∫₀^0.5 2(1−x) dx = [2x − x²]₀^0.5 = 1 − 1/4 = 3/4 = 0.75
```

直觉版：把 q 画出来是一条从 2 直线降到 0 的斜线；x<0.5 那一半下面的面积是整个三角形面积的 3/4（斜线在中点处还剩一半高度，但左半边全是"高处"）。数值核验：100-bin 精确 bin 概率求和 `Q = 0.75`（浮点残差 1×10⁻¹⁶）。

## 2.2 近区质量 recurrence

第 `t+1` 轮近区质量 = 未被拿走的 `(1−alpha)·M_t` + 重泼落回近区的 `alpha·M_t·Q`：

```text
M_{t+1} = M_t · [1 − alpha·(1−Q)] = M_t · (1 − alpha/4)
```

baseline `alpha = 0.25`：`M_{t+1} = M_t · 15/16`，故 `M_t = 0.75·(15/16)^t`。

**与已提交 CSV 的逐轮核对**（`EXP-M0-A_deterministic.csv`，31 轮全查）：最大偏差 `4.87×10⁻¹¹`，该偏差完全来自 CSV 十位小数的打印舍入（≤5×10⁻¹¹）；对内存中全精度模拟序列的最大偏差为 `1.7×10⁻¹⁶`（浮点级）。核验代码：`tests/test_m0_mechanism.py`。

## 2.3 精确解：整条轨迹是 z 的一维路径

**命题**：对任意 alpha（含边界 0 与 1），deterministic 精确解为

```text
近区（i < 50）：  m_i(t) = z_t · q_i,      z_t = ρ^t,  ρ = 1 − alpha·(1−Q)
远区（i ≥ 50）：  m_i(t) = λ_t · q_i,      λ_t = (1 − Q·z_t)/(1−Q)   （M0-A: 4 − 3z_t）
```

**归纳证明**：t=0 时 z=1、λ=1，状态为 q ✓。设 t 时成立，近区质量 `M_t = Q·z_t`：

- 近区：`m_i' = (1−alpha)·z_t·q_i + alpha·Q·z_t·q_i = z_t·q_i·(1 − alpha(1−Q)) = z_{t+1}·q_i` ✓
- 远区：`m_i' = λ_t·q_i + alpha·Q·z_t·q_i`，且 `λ_{t+1} = λ_t + (alpha·Q/(1−Q))·z_t`；由 `λ_t = (1−Q·z_t)/(1−Q)` 直接验证 ✓
- 总质量：`Q·z + (1−Q)·λ = Q·z + 1 − Q·z = 1` ✓（对一切 z 守恒）

数值核验：对 alpha ∈ {0, 0.1, 0.25, 0.5, 0.75, 1.0}，闭式解与逐步模拟器（`run_deterministic_states`）逐 bin 最大偏差 ≤ 2.2×10⁻¹⁶。**因此 deterministic M0-A 的全部状态由单一变量 z 描述。**

## 2.4 U(z) 是精确二次函数

利用 `Σ(p_i − 1/K)² = Σp_i² − 1/K`（因 Σp_i = 1），记 `S_n = Σ_{近} q_i²`、`S_f = Σ_{远} q_i²`（精确值：`S_n = 0.0116665`，`S_f = 0.0016665`，由 bin 概率精确求和得到）：

```text
U(z) = z²·S_n + λ(z)²·S_f − 1/K
     = S_n·z² + S_f·((1 − Q·z)/Q_f)² − 1/K
     = (S_n + 9·S_f)·z² − 24·S_f·z + (16·S_f − 0.01)      （代入 Q=3/4, Q_f=1/4）
```

（线性项在一般形式中已消去：`z·Q + λ·Q_f ≡ 1`。）

**数值核验**：该二次式重现已提交 CSV 的 U 列至 `4.9×10⁻¹⁵`，重现全部六个 alpha 的模拟 U 至 `≤ 2.8×10⁻¹⁷`——**它不是近似，而是离散实现的精确代数等价**。

## 2.5 最优点

```text
z* = Q·S_f / (Q²·S_f + Q_f²·S_n)        （二次式求根）
```

- **连续版本**（`S_n = Δ·7/6`，`S_f = Δ·1/6`，比值精确 7:1；Δ=1/K）：`z* = 0.75·(1/6)/(0.5625/6 + 0.0625·7/6) = 3/4`，**精确等于 3/4**。此时 `U_cont(z) = (2/75)z² − (1/25)z + 1/60`，最小值 `U_cont(z*) = 1/600 ≈ 1.6667×10⁻³`，且 `U_cont(1) = 1/300 ≈ 3.333×10⁻³`（与离散 t=0 值一致）。
- **离散 100-bin 实现**：`z* = 12·S_f/(S_n + 9·S_f) = 0.74997187`，对 3/4 的有限-bin 修正为 **−2.81×10⁻⁵**（比值 7:1 在离散下为 7.0006）。`U(z*) = 1.6660625×10⁻³`（连续 1.6666667×10⁻³，差 6×10⁻⁷）。
- **连续 t\***：`t* = ln(z*)/ln(15/16) = 4.4581`（用连续 z*=0.75 得 4.4576）。

**结论：候选结果"U 化为 z 的二次函数、在 z=3/4 附近最小、t≈4.46"成立**；需要注明的是：连续表达式与 histogram 指标**结构相同但非逐值相同**——离散实现存在 −2.8×10⁻⁵ 的 z* 修正与 ~6×10⁻⁷ 的 U 修正（均为有限-bin 效应，随 K→0 消失）。

## 2.6 轮次离散化：浅平台与可达性

baseline：`z_4 = 0.772476`、`z_5 = 0.724196` 从两侧夹住 `z* = 0.749972`；`|z_4 − z*| = 0.02250 < |z_5 − z*| = 0.02578`，且 U 是 z 的抛物线，故 `U(4) = 1.679567×10⁻³ < U(5) = 1.683778×10⁻³`（差 0.25%）。**这就是 t=4/t=5 浅平台的完整解释。**

离散可达最优与连续最优的差距（discretization gap，`U(最佳整数轮) − U(z*)`）：

| alpha | 0.10 | 0.25 | 0.50 | 0.75 | 1.00 |
|---|---|---|---|---|---|
| gap | 1.29×10⁻⁶ | 1.35×10⁻⁵ | 6.53×10⁻⁶ | **1.04×10⁻⁴** | 2.11×10⁻¹¹ |

alpha=1.00 的 z 网格第一拍就是 0.75，精确命中连续最优（gap 为浮点级）；alpha=0.75 的网格（0.8125, 0.6602, …）跳过 z* 最远。**"底层最佳状态相同"（对一切 alpha 严格成立）与"离散可达最佳相同"（随 alpha 变化）由此区分。**

## 2.7 MC 粒子版本无系统偏离

多批次直方图的期望给出 `E[U_MC] = U(z_t) + (1 − 1/K)/N`（噪声底线 9.9×10⁻⁶）。M0.1 spot check（alpha ∈ {0.25, 0.75, 1.0}，各 5 种子，N=10⁵）：单种子最大偏差 1.3–1.4×10⁻⁴（多项抽样尾部），5 种子均值对"理论+底线"的最大偏差 3.7–6.5×10⁻⁵（三种 alpha 共用同一批种子，偏差方向相关）。追加 40 种子收敛探针（alpha=0.25）：各轮 `mean(U_MC − U(z_t)) = +0.5×10⁻⁵ … +1.1×10⁻⁵`，全部落在理论底线 9.87×10⁻⁶ 的 ±1σ 内——**粒子版本无系统偏离，其期望偏差就是有限样本噪声底线**。
