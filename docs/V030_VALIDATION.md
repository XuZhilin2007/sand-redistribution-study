- 新证明采用 GitHub 支持的行内数学保护语法与 math 围栏；两张 G 表清除
  行间空白。逐式核对格式整理前后的 TeX；一处带嵌套美元符号的公式标签
  改为 W-k，公式主体不变。原 S3 的中英文 18 个编号公式未修改。

## 2.1. GitHub 大文件限制与无损传输

普通 Git 推送因 B 证书约 266 MiB 超过 GitHub 的 100 MiB 单文件限制被拒，
原子推送没有更改远端。公开版本重新从原公开 main 创建快照，保留失败候选的
本地提交，不改写任何已发布历史。B/E 原始 JSON 改以 gzip 分片存储，
首次运行 `tools/materialize_v030_certificates.py` 即离线恢复原路径。

运输格式验收 **8/8 PASS**：隔离目录完整恢复、两文件逐字节 SHA 一致、
重复执行、错误逻辑哈希拒绝、损坏压缩数据拒绝、修复后恢复及无残留临时文件。
所有数学生成器、原测试和恢复后的证书字节与 610 项回归的验收输入完全一致。
分片分别校验，最终 JSON 的大小和 SHA 再与科学文件清单核对。

原始 JSON 的 370 项逻辑文件摘要继续按恢复后的原始字节定义；
Git 对象验收将压缩存储还原后比较。压缩不改变证明、字段或数值。
私有完整历史以保留原提交 ID 的 Git bundle 另存现有私有仓库的归档 Release，
不为绕过上传限制重写研究历史。

精确族证书的全称量词与独立引擎的有限轨迹采样分开读取。
JSON 证书和原始实验数据保持原内容；为保留证书所哈希的实际源码字节，
本版固定 CRLF/LF 原始表示。历史私有 Git blob 与运行字节仅有换行差异的
条目另行记录，不手工修改旧证据的 Git 或 SHA-256 字段。

继承的 176 个旧私有 Git blob 与公开字节仅有 CRLF/LF 差异，范围与
v0.2.0 记录一致；旧历史不改写。其余 194 个清单文件在两仓中
逐字节相同（公开 B/E 按还原后的逻辑文件比较）。本版全部科学工作区文件
与公开还原字节一致。

两仓完整回归、独立验证和发布内容检查全部通过。正式版本以
[v0.3.0 标签](https://github.com/XuZhilin2007/sand-redistribution-study/tree/v0.3.0)
和 [GitHub Release](https://github.com/XuZhilin2007/sand-redistribution-study/releases/tag/v0.3.0)
为准；发布操作随后核对这些远端对象与已验收提交的对应关系。
