## 1. 推导出的精确词典（Owner 候选被逐字证实）



标量闭包（T4′）：x>h 时 x′=(1−α)x+αL；x≤h 时 x′=x+α(c−x)q（L=cq）。

两支都可写成 **同一截距 αL**：A(x)=(1−α)x+αL，B(x)=(1−αq)x+αL。



令 u₋=A(h)=(1−α)h+αL，u₊=B(h)=(1−αq)h+αL，D=u₊−u₋=**αh(1−q)**，

U=(u₋,u₊]（CYCLE 类上 u₋<h<u₊，一步不变——脚本逐点验证）。

共轭坐标 z=(u₊−x)/D（x>h ⟺ z<η）：



- **A 支**：z′=(u₊−[(1−α)x+αL])/D=(1−α)z+α(u₊−L)/D，即 **z′=λz+δ**；

- **B 支**：z′=(1−αq)z+α(qu₊−L)/D；因 qu₊−L=(1−αq)(qh−L)=−(1−αq)q(c−h)，

  得 z′=(1−αq)(z−η)=**μ(λz+δ−1)**（用 1−δ=λη，即 η=(1−δ)/λ）。



**词典（精确）**：



| LN 参数 | 本模型（(α,K) 的显式函数） |
|---|---|
| λ | 1−α |
| μ | (1−αq)/(1−α) = β/(1−α)，β=1−αq |
| δ | 1−(1−α)η（=α(u₊−L)/D，推导原值逐点相等） |
| η_LN | q(c−h)/((1−q)h) —— **完全不含 α** |



与 α=1/4 已收录版本一致（λ=3/4，μ=4β/3）。η 的 α 消去是初等的：

u₊−h=αq(c−h) 与 D=αh(1−q) 的公因子 α 相消。

## 8. 端点例外在一般 alpha 下确实发生（精确证明；2026-10-19 Owner 发现并给出恒等式，本仓独立核验后入库）

取 canonical K=10（q=1/15、eta=89/140）。记 lambda=1-alpha、beta=1-alpha/15（故 mu=beta/lambda）、

- H = (1+lambda)(1+lambda·beta) + lambda^2·beta^2，
- P(alpha) = 17·alpha^4 − 99·alpha^3 − 2448·alpha^2 + 8230·alpha − 1875。

**引理 G-ep（精确多项式恒等式）。** 对一切 alpha，

    delta_K(alpha) − delta^+(lambda, beta/lambda, 2/5) = lambda · P(alpha) / (10500 · H).

（delta_K = 1 − lambda·eta；delta^+ 取 LN 定理 1 的 p/q=2/5 显式公式，其中 S=lambda^2。本仓以有理系数多项式运算独立验证两端为同一个有理函数——零残差；此前版本以 50 位数值接近代替此步，不构成证明，现予替换。）

**定理 G-ep（端点例外的存在性与唯一性）。** 对 0<alpha<1：lambda>0；H>0（正项之和）；P(0)=−1875<0<P(1)=3825；且

    P'(alpha) = 68·alpha^3 − 297·alpha^2 − 4896·alpha + 8230 >= 3037 > 0,

故 P 在 (0,1) 严格递增，有**唯一**根 alpha* 属于 (0,1)（有理括号 0.245996<alpha*<0.245997 精确可验：P 在两端点取异号）。由引理 G-ep，alpha=alpha* 时

    delta_K(alpha*) = delta^+(lambda(alpha*), mu(alpha*), 2/5)

**精确成立**。alpha* 是四次整多项式的根，为代数数，故 (lambda, mu, delta)(alpha*) 皆为代数数：LN 定理 2 给出有理旋转数（在右端点处 rho=2/5），而 LN 定理 3(iii) 适用——f **没有真周期轨道**，一切轨道收敛到有限 omega-极限集 phi(I)（含端点 1；左极限映射 f^- 有 q-周期轨道）。证毕。
