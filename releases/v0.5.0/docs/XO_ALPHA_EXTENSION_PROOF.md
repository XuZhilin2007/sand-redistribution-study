## 1. 模型与记号

p_i≥0，Σp_i=1；F_j=Σ_{i≤j}p_i，D_j=F_j−j/K，d=max_j D_j。
s=min argmax_j D_j；仅当 d>τ=10⁻¹² 时更新：
p'_i=(1−α)p_i+αF_s g_i（i≤s），p'_i=p_i+αF_s g_i（i>s）。
canonical 初态 p_{0,i}=(2K−2i+1)/K²。

XO CDF：
G(y)=y/2（0≤y≤1/3），3y/2−1/3（1/3≤y≤2/3），
2y−2/3（2/3≤y≤5/6），1（5/6≤y≤1）。
g_i=G(i/K)−G((i−1)/K)。

记 h=1/K，r=K mod 6，m=ceil(5K/6)，ℓ=m−1，b=m/K，
c=2b−b²，a=b(1−b)，q=g_m=(6−r)/(3K)，L=cq。
有 5/6≤b≤10/11，c≥35/36，a≥10/121>τ。

## 2. T1′：不变量与不停机

对所有 t，s_t≤m，F_{t,m}=c，D_{t,m}=a，D_{t,j}<a（j>m），d_t≥a>τ。

初态 D_{0,j}=(j/K)(1−j/K)，故所有 j>m 的 D_{0,j}<a。
若 s≤m，则对 j≥m，G_j=1，F'_j=F_j−αF_s(1−G_j)=F_j。
因此以上支配关系与 F_m=c 保持，下一次选择仍≤m。归纳完成。

## 3. T2′：有限进入及显式时间界

累积更新式为
D'_j=(1−α)D_j+α(F_s G_j−jh)（j≤s），
D'_j=D_j−αF_s(1−G_j)（j>s）。

对内部 j≤m−2，置 L_j=cG(jh)−jh。原 S3 证明 P1 的几何界给出
a−L_j≥29h/108，1−G_j≥2h。
对于 jh≤2/3，G(jh)≤jh，L_j≤0，而 a≥10/121≥29h/108。
对于 2/3<jh<5/6，写 z=b−jh≥2h：
a−L_j=(2c−1)z−crh/3≥h[c(4−r/3)−2]≥29h/108。
K=6 的三个内部点全部位于 jh≤2/3，故无需错误的共同上界。

当 D_j≥a，被扫坐标由 F_s≤c 得到下降至少 α(a−L_j)；
未扫坐标由 F_s=sh+d≥a 得到下降至少 αa(1−G_j)。
因此每轮至少下降
α min{29h/108,2ah}≥20α/(121K)。
初始超出 a 的缺口≤1/4−a≤81/484。
故区域 (R)：D_j<a（所有 j≤m−2）至迟在
T_α=floor(81K/(80α))+1
达到；(R) 前向不变，因为被扫更新是 D_j 与 L_j<a 的严格凸组合，
未扫坐标继续下降。首次边界选择 t*≤T_α。
这是原来较松的 floor(81K/(20α))+1 的四倍改进；
α=1/4 时恢复底本 floor(81K/20)+1。

## 4. T3′：从首次边界选择起持久，对所有 K≥6

首次选择 ℓ 或 m 时，所有内部坐标严格低于 max(D_ℓ,D_m)；
内部平局会优先选较小的内部指标，所以不可能留有最大值内部平局。

K≥7：若选择 m，则所有内部坐标已<a，(R) 保持。
若选择 ℓ，x=p_m≤h，w=F_ℓ=c−x≥c−h≥29/36。
置 H(y)=wG(y)−y：
D'_ℓ−D'_j=(1−α)(D_ℓ−D_j)+α[H(ℓh)−H(jh)]。
H 在第一段递减，在后两段严格递增。原 S3 证明 P2 的端点界
H(ℓh)−H(h)≥Z_K=(c−h)(1−q−h/2)−b+2h>0，
结合单调性给出 H(ℓh)>H(jh)（内部 j）。
其全 K 正性来自底本的恒等式：K=6n+r、u=n−1 时
6K³Z_K=180u³+(231+136r)u²+(12+152r+30r²)u
+2r³+19r²+31r−39。
r=1..5 的常数为 13,115,279,517,841，其余系数正；
r=0、K≥7 时 u≥1，右侧至少384。
严格正的凸组合保持内部支配。

K=6：m=5、ℓ=4、a=5/36。s₀=3，第一轮
D_{1,1}=5/36−35α/144<a，此后该坐标由 P1 单坐标不变性永久<a。
选择 ℓ 时 w≥29/36，另外两个内部坐标满足
H(4h)−H(2h)=w/2−1/3≥5/72>0，
H(4h)−H(3h)=w/4−1/6≥5/144>0。
上述凸组合使 D'_4>D'_2,D'_3；坐标1仍<a。
选择 m 时 (R) 已成立。故 K=6 也从首次边界选择起持久。

辅助的一步案例分析：
D_{1,3}=(4−7α)/16，D_{1,4}=2/9−α/4，
s₁=3（α≤4/27），s₁=4（4/27<α≤1/3），s₁=5（α>1/3）。
该分析与首次进入持久性证明分别承担不同任务。

## 5. T4′：边界标量闭包

对 t≥t*，令 x_t=p_{t,m}，则
s_t=m iff x_t>h；x_t=h 时选择 ℓ；
d_t=a+(h−x_t)^+。
更新为
x'=(1−α)x+αcq（x>h），
x'=x+α(c−x)q（x≤h）。
这描述边界坐标与边界观测量，不重构全质量向量。
x=h 时下步严格上穿，但 d 仍为 a；A→B 若恰好落在 h，
也属于选择切换，不必是严格 discrepancy rebound。

## 6. T5′：无限时间二分

上支不动点 L=cq，下支不动点 c，均不依赖 α。
上支活跃 n 步时 x_n=L+(1−α)^n(x₀−L)；
下支活跃 n 步时 c−x_n=(1−αq)^n(c−x₀)。

L≥h 时，上支前向不变；下支有限步上穿，之后永久选择 m。
L<h 时，上支有限步到 x≤h，下支有限步到 x>h，故两支均无限次出现。

L/h=c(6−r)/3：
r=0,1,2 时≥(35/36)(4/3)>1；
r=3,4,5 时≤c<1。
因此所有 K≥6、0<α<1 的无限时间二分由 r 决定。

## 7. 有限窗口边界

T5′ 不是冻结 H=10K 分类器的 α 普适性定理。
精确反例：K=9、α=1/8、H=90，t*=3，R_m=10，冻结分类器
优先检查 R_m≥K，输出 LOCK；进入后两支均已出现，无限时仍双支切换。
K=10、α=1/1000、H=100 可输出 OTHER（窗口内未进入）。
改变 α 时，进入时间、驻留长度与尾长判定均需分别检查。

不涉及周期性、全状态渐近、其他初态/律、有限精度保证或一般二维模型。
