## 1. 模型与主定理

固定整数 K≥6、移除比例 α，采用 canonical 初态

```math
p_{0,i}=(2K-2i+1)/K^2,\qquad i=1,\ldots,K.
```

记 h=1/K、F_j=Σ_{i≤j}p_i、D_j=F_j−jh，每轮选择
s=min argmax_j D_j。XO 的 CDF 为

```math
G(y)=\begin{cases}
y/2,&0\le y\le1/3,\\
3y/2-1/3,&1/3\le y\le2/3,\\
2y-2/3,&2/3\le y\le5/6,\\
1,&5/6\le y\le1,
\end{cases}
\qquad g_i=G(i/K)-G((i-1)/K).
```

若 max_jD_j>τ=10⁻¹²，执行

```math
p'_i=\begin{cases}
(1-\alpha)p_i+\alpha F_sg_i,&i\le s,\\
p_i+\alpha F_sg_i,&i>s.
\end{cases}
```

定理 A 给出该 canonical 轨道 max_jD_j≥10/121>τ，故轨道在全部整数时间有定义并持续更新。以下“停止”指选择一个整数时间结束这条既定轨道。

**主定理。** 在精确算术与上述最小指标平局规则下，令

```math
J=[1999/8000,2001/8000]=[0.249875,0.250125],\qquad
U(p)=K\sum_{i=1}^K(p_i-1/K)^2.
```

则

```math
\forall K\in\mathbb Z_{\ge6}\quad\forall\alpha\in J\quad
\forall t\in\mathbb Z_{\ge0}:\qquad U(p_t)\ge U(p_2).
```

其中 α 遍历 J 内全部实数；证书的有理系数与精确有理区间运算负责覆盖整个实区间。该结果给出与 K 无关的双侧半径 δ=1/8000。v0.3.0 的 α=1/4 全 K 结果是其特例。

结论断言 t=2 是全局最优整数停止时刻，不要求最优时刻唯一、最早或后续损失单调。模型、初态、喷撒律、平局规则与损失均为声明范围的一部分。

6. [独立有限证书验收器](../tools/audit_v04_interval_v3.py)：原见证共 207 个分片、80,246 条精确符号义务。平局 K∈{16,32,96,160} 采用左右分片；各片使用自己的真实 U₂，不假设跨支连续。

边界进入后的两支更新都使残差乘 ρ=1−α，因此无需固定未来选择字。损失恒等式为

```math
U(p_t)=Ax_t^2+Bx_t+C+2z(dx_t+f)+Ez^2,\qquad z=\rho^{t-2}.
```

使用缩放矩 C_g=KΣgᵢ²、Z=KΣgᵢeᵢ、E=KΣeᵢ²（均对 i<m 求和），有

```math
A=K+\frac{C_g}{(1-q)^2},\qquad d=-\frac{Z}{1-q},\qquad
H_2=E-\frac{d^2}{A}
=\frac{K(1-q)^2E+C_gE-Z^2}{A(1-q)^2}\ge0.
```

最后一步来自 E≥0 与 Cauchy–Schwarz 的 C_gE≥Z²。配方后 H 在 [0,ρ] 上递减，所以全部 K≥204、α∈J、整数 t≥3 实际满足严格余量

```math
U(p_t)-U(p_2)>1/100.
```
