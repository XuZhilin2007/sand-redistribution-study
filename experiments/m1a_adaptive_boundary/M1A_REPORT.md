# M1A 实验报告：自适应扫掠边界 vs 固定边界 M0

> 日期：2026-09-18
>
> 模型定义：[docs/M1A_MODEL.md](../../docs/M1A_MODEL.md)；代码：`src/sand_m0/adaptive.py`；配置：[config.json](config.json)（运行前冻结）
>
> 证据等级：adaptive rule 为 **模型假设**；可推导结构为 **模型推导数学结果**；数值对照为 **已验证模拟结果**；跨模型比较为 **模型依赖观察**。全部只对 M1A/M0 模型成立。

## 1. 四个研究问题与答案

| 问题 | 答案 |
|---|---|
| 1. 状态反馈下 finite-time optimum 是否仍存在？ | **不再以 M0 的形式存在**。M1A 的 U 轨迹没有"早熟最佳+恶化"：它持续缓慢改善（带波动），最好状态出现在 t=98（几乎在预算末端）。M0 的 interior optimum 是固定区域动力学的产物。 |
| 2. adaptive feedback 是否减少/避免 near-zone depletion 与 overshoot？ | **是，完全避免**（已验证模拟结果）：固定近区 [0,0.5] 的质量全程 ≥ 0.5011（理想 0.5），M0 塌缩到 0.00118；M1A 终态 U = 1.70×10⁻⁴，M0 终态 1.66×10⁻²（比初始还差 5 倍）。 |
| 3. alpha time-rescaling 是否被破坏？ | **是，恰好在第二个决策处破坏**（模型推导 + 模拟验证）：a(0)=0.5 对所有 alpha 相同（首轮与 M0 逐位相同）；a(1) 有闭式 `x*=(2λ−1)/(2λ)`，随 alpha 变为 {0.53, 0.58, 0.64, 0.71}；此后各 alpha 是不同过程（最佳轮 94/98/89/53，最佳 U 各异）。 |
| 4. 是否自然进入"无近侧过剩"的停止状态？ | **q_near 下不停止**：D_max 从 0.25 波动衰减至 ≈0.05，100 轮内始终为正——近偏重泼（75% 回近区 vs 50% 均匀份额）在结构上持续再造过剩。对照分布（均匀、远偏）**第一步即停**（D_max ≈ 0）。 |

## 2. 实现与配置

- `src/sand_m0/adaptive.py`：`cumulative_excess`、`boundary_decision`、`excess_margin`、`run_m1a_deterministic`、`run_m1a_mc`；行与状态对齐（row t = 状态 t 指标 + t→t+1 决策），与 M0 的 `run_deterministic` 同一约定。
- 冻结参数：q_near、alpha=0.25 基线、K=100、T_max=100、stop_tolerance=10⁻¹²（数学条件 D_max ≤ 0 的数值实现，冻结不调）、MC N=10⁵ × 5 种子（20260917–21）。
- 测试：`tests/test_m1a_adaptive.py`（18 项）通过；M0/M0.1/M0.2 全部既有测试（37+25+53 项）保持通过。
- 复现命令：`.venv/Scripts/python.exe experiments/m1a_adaptive_boundary/run_experiment.py`

## 3. M0 vs M1A（同代码、同 q、同 alpha、同指标、同初始状态）

| 指标 | M0（固定 a=0.5，T=100） | M1A（自适应边界，T_max=100） |
|---|---|---|
| 最佳轮 | 4 | 98（近预算末端） |
| 最佳 U | 1.6796×10⁻³ | **1.4863×10⁻⁴**（低 11.3 倍） |
| 终态 U（t=100/99） | 1.6601×10⁻²（比最佳差 9.9 倍，比初始差 5 倍） | 1.7040×10⁻⁴（与最佳同量级） |
| 近区 [0,0.5] 终态质量 | 0.00118（完全掏空） | 0.51531（贴近理想 0.5） |
| 近区质量最小值 | 0.00118 | 0.50111 |
| 过冲（终态差于最佳） | 严重 | 无（终点仍在波动） |
| 执行扫掠次数 | 100 | 100 |
| 自然停止 | 不存在停止机制 | **未发生**（D_max ≈ 0.05 > tol） |
| 轨迹特征 | 单一 z-路径，解析已知 | 振荡边界，无闭式 |

- **U 轨迹分岔点**：t=0、t=1 两模型逐位相同（首轮边界同为 0.5，已证明）；**t=2 起分离**（M1A 2.165×10⁻³ vs M0 2.109×10⁻³）。
- 公平性说明：M1A 的"最佳 U 在 t=98"锚定在预算末端——它不是 M0 意义上的 finite-time optimum，而是"仍在上坡路"的状态；本轮不将其解读为收敛。

## 4. Adaptive boundary trajectory

- 首决策 `a(0)=0.5`（D₀(x)=x(1−x) 的精确峰）；第二决策闭式 `x*=(2λ−1)/(2λ)` → a(1)=0.58（baseline）。
- 此后**振荡**：a_t ∈ [0.21, 0.97]（均值 0.595），无固定路线。机制：扫掠边界之外过剩只减不增（可证明），边界之内被重泼回填——argmax 在"已扫衰减区"与"回填再造区"之间来回跳。
- **边界选择每轮都是近平局**：最优与次优前缀的过剩差（D_margin）全部 101 次决策 < 0.005（中位数 1.0×10⁻⁴，最小 3.3×10⁻⁷）。状态并不指定唯一"正确"的扫掠点——这是规则对噪声天然敏感的结构根源（本轮只记录，不引入平滑修补）。
- D_max 非单调：34 次回升，最大一次 0.0162→0.0671（t=89 附近）。与 M0 的单调几何衰减形成对照。

## 5. Natural stopping

- **停止判据的行为学含义**：D_max ≤ 0 ⟺ 状态 CDF 被均匀 CDF 处处支配（每个前缀不过剩）——这是模型内"操作者不再看到近侧过剩"的精确刻画；注意它**不**蕴含 U=0（停止态允许远端过满）。
- **q_near**：不停止（见 §1 问题 4）。结构性原因：重泼的近区份额 75% > 均匀份额 50%，每轮扫掠都在近侧重造过剩。
- **对照**：q_uniform（D≡0）与 q_far（D≤0）在 t=0 立即停止、扫掠 0 次——验证停止机制本身工作正常（`fig_initial_cumulative_excess.png` 直观展示三条 D 曲线）。

## 6. Alpha time-rescaling test（可证伪假设：被证伪）

| alpha | a(1)（闭式/模拟） | 最佳轮 | 最佳 U | 终态 U | 停止 | a_t 范围 |
|---:|---|---:|---:|---:|---|---|
| 0.10 | 0.535/0.53 | 94 | 2.608×10⁻⁴ | 2.72×10⁻⁴ | 否 | [0.23, 0.93] |
| 0.25 | 0.579/0.58 | 98 | 1.486×10⁻⁴ | 1.70×10⁻⁴ | 否 | [0.21, 0.97] |
| 0.50 | 0.636/0.64 | 89 | 2.277×10⁻⁴ | 2.50×10⁻⁴ | 否 | [0.21, 0.98] |
| 1.00 | 0.714/0.71 | 53 | 7.874×10⁻⁴ | 1.06×10⁻³ | 否 | [0.24, 0.99] |

- 全部 alpha 在 a(0)=0.5 处起步相同；**第一个分岔在第二个决策（t=1）**；U 序列从 t=2 起实质不同（非时间重标的同一曲线）。
- alpha 现在真正改变轨迹与可达状态：不同 alpha 的最佳 U 不同（1.49×10⁻⁴ … 7.87×10⁻⁴），alpha=1.0 的快速大步扫掠反而更差。**alpha 从"纯时间参数"变成了"改变过程的参数"。**

## 7. Monte Carlo spot check

5 种子（N=10⁵，alpha=0.25）：终态 U = 1.39–2.02×10⁻⁴，围绕 deterministic 终态 1.70×10⁻⁴ 波动，无系统偏移。**边界翻转计数**：MC 与 deterministic 的每轮 a_t 在 93–99/100 轮不同——但这同时包含轨迹分岔与决策噪声；更干净的结构证据是确定性 margin 本身：每轮 top-2 过剩差 < 0.005（§4），决策天然处于近平局。**本轮不加入 smoothing 修补**；该现象是未来"visual smoothing / perceptual scale"研究的直接动机（已记录于研究日志）。

## 8. Mathematical structure / what broke from M0

**保留的（模型推导数学结果）**：
1. D(K)=0 恒成立 → D_max ≥ 0；D_max=0 ⟺ 状态 CDF 处处被均匀支配（停止态精确刻画）；
2. q_near 首轮边界 a₀=0.5 精确 → M1A 首轮更新与 M0 逐位相同；
3. 第二决策闭式 `x*=(2λ−1)/(2λ)`（随 alpha 单调右移，模拟 4/4 吻合）；
4. 边界之外过剩单调不增：`D_{t+1}(x) ≤ D_t(x) ∀x>a_t`。

**破坏的**：
1. 单一 z-路径描述——扫掠算子由状态决定（分段线性切换），轨迹不再是单参数曲线；
2. alpha time-rescaling——alpha 进入决策，成为过程参数；
3. finite-time interior optimum（M0 意义）——被"持续改善+波动"替代；
4. D_max 的单调性——M0 近区质量单调衰减，M1A 的过剩有 34 次回升。

无闭式解的部分（边界序列、U(t) 全局形态、停止时刻）如实留在模拟侧。

## 9. Unexpected results（原样保留）

1. **边界决策永远近平局**（101/101 次 margin<0.005）——比"MC 翻转 93–99/100"更根本：即使无噪声，"该扫到哪里"也只被状态弱确定性。
2. **M1A 不停止**——任务预期之一是可能停止；实际近偏重泼使停止态（CDF 被均匀支配）在结构上难以到达。
3. **最佳状态几乎贴着预算末端**（t=98/100）——M0 的"早熟最佳+恶化"完全消失，取而代之的是缓慢爬坡+持续波动；预算长度本身成为结果的一部分（诚实记录，不外推）。
4. **alpha 与结果非单调**：alpha=0.25 的最佳 U 好于 alpha=0.10 与 0.50，更远好于 1.00——反馈过程存在中等强度优势的迹象，但 4 个点不足以下此结论，仅记录。
5. **近区质量最小值 0.5011 出现在过程中**——自适应规则把固定近区"托"在理想份额之上，是"避免过冲"的最直接证据。

## 10. Evidence Classification

- **模型假设（Model Assumption）**：adaptive boundary rule 与 stop_tolerance（最小数学抽象，非真实视觉规则）。
- **模型推导数学结果（Model-derived Mathematical Result）**：§8 保留列的四条性质 + time-rescaling 的破坏点证明（第二决策）+ 停止态刻画（CDF 支配）。
- **已验证模拟结果**：M0/M1A 100 轮轨迹、controls 立即停止、alpha 结构表、MC 波动、margin 统计——固定 config/代码 commit 可一条命令复现。
- **模型依赖观察**：M1A 优于 M0 的全部比较、最佳轮贴预算末端、alpha 非单调——依赖 q_near、a 的比较框架、T_max=100、tol=10⁻¹²、K=100。
- **工作猜想**：若重泼分布的近区份额接近均匀份额（或重泼随状态调整），自然停止可能变得可达；真实操作者的"看哪里、扫到哪里"对应一个感知尺度上的 D 最大化的粗粒化版本。
- 本轮无 Literature-supported Result；adaptive rule 不构成 Real-world Observation。

## 11. What This Does NOT Prove

- 不证明自适应反馈在真实沙坑中更优（模型内结论）；
- 不证明 M1A 的停止判据对应人的停止判断（无视觉阈值、无容忍度建模）;
- 不证明 D_max 单调收敛（实际观察到非单调）；
- 不证明 alpha=0.25 最优（4 点结构检查，非优化）；
- 不证明边界振荡不是 K=100 离散化伪影（未做 K 敏感性——留待后续）；
- 不进入 local smoothing、remote dense blocks、2D、真实实验（等待 Owner + GPT review M1A）。

## 12. Recommended Next Research Question

**M1B（建议，待 Owner+GPT 批准）**：停止判据与重泼分布的相互作用——若把重泼分布换成均匀或弱近偏（c_n/c_f 接近 1），D_max 能否穿过 0 并自然停止？这能把"为什么不停止"从 q_near 的个案推进为"重泼偏置强度 vs 停止可达性"的一般关系，并与 Phase 2A 的判据衔接。之后的候选：感知尺度上的 D 平滑（对应 margin 近平局问题）。

## 14. Limitations

1. 单一 q_near 基线 + 两个立即停止的对照；"何时停止"的一般条件未刻画（§12 建议）。
2. argmax 的近平局与 K=100 离散化的相互作用未做敏感性分析。
3. 停止判据是纯前缀判据，不含"远端孤立块"（真实操作者也会处理中远密集块——超出本轮范围）。
4. MC 边界翻转计数混合了轨迹分岔与决策噪声两种效应，解释时已加区分。
